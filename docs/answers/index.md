# 疑問に答える
{: .no_toc }

検索して辿り着いた人向けに、**1ページで1つの疑問に答えます。**

詳しい手順は[ガイド](../guide/ja/)に、ツール同士の比較は[他の選択肢との比較](../guide/ja/alternatives.html)にあります。
ここは、その入口です。

**断っておくと、このページを書いているのは MulmoTerminal を作っている側**です。中立ではありません。
その代わり、他のツールが向く場面と、**この製品を使わずに済ませる方法**を先に書きます。
