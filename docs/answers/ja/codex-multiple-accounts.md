# Codex の契約を複数使い分けるには
{: .no_toc }

**セルごとに手で選びます。** Claude のような自動の振り分けは、Codex にはありません。

## 仕組み

Codex は、設定とログインを `CODEX_HOME` の下に置きます。**このディレクトリを契約ごとに分ければ、
別の契約として並べられます。**

MulmoTerminal では、分けたディレクトリをアカウントとして登録します。

```json
{ "id": "personal", "label": "個人", "agent": "codex", "home": "~/.codex-personal" }
```

設定画面からも足せます。**設定 → モデルとバックエンド** の「2つ目以降の契約」に、
名前と、Codex であることと、ディレクトリを入れます。

## `~/.codex` そのものは指定しない

いつものログインのディレクトリです。ここを指定すると、そのアカウントのセルは
単にいつものログインで動き、専用の使用枠も出ません。

**新しいディレクトリを作って、そちらを指定します。**

## 使い方

1. 空のセルで Codex を選びます
2. モデルの下に **ACCOUNT** の選択欄が出ます
3. 「Default login」（いつものログイン）か、登録した契約から選びます

枠ごとに別の契約を選べるので、6枚のうち2枚だけを仕事用の契約で動かす、といった使い方ができます。

## 最初のログイン

新しいディレクトリのアカウントは、**空の状態から始まります。**

自分の設定も、登録した MCP サーバーも、プロジェクトごとの信頼の回答も、
いつものログインのものです。新しいほうには引き継がれません。最初のセッションで聞かれます。

## 使用枠の表示

Codex のアカウントでは、**使用枠を出すための追加の手順は要りません。**
そこで最初のセッションを動かしたあと、そのアカウントのセッションの記録から読みます。

まだセッションを動かしていないアカウントは、ツールバーに何も出ません。
一度動かせば出るようになります。

## Claude との違い

| | Claude | Codex |
|---|---|---|
| セルごとに契約を選ぶ | できる | できる |
| 自動で余裕のある契約を選ぶ | できる | **無い** |
| 上限が近づいたら別の契約へ移す | できる | **無い** |
| 使用枠を出す準備 | 手順が要る | 要らない |

**自動の振り分けは Claude だけです。** 残りを時間で割って選ぶ仕組みは、
[トークンのローテーション](../guide/ja/token-rotation.html)に書きましたが、Codex は対象外です。

Codex では、どのセルをどの契約で動かすかを自分で決めることになります。
