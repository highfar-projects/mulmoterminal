# 10.2.0 — 全画面プレビューの数式、ShapeScript、エディタと Canvas 表示の横並び

**10.2.0（2026-10-12 リリース）時点のスナップショットです。** アプリが変わればこのページは古くなります。それは
想定どおりで、最新の説明は各節がリンクしているガイドにあります。

## 新機能

### 全画面のプレビューで数式が描かれる

全画面のファイル表示（`/files`）の Markdown の **Preview** では、`$…$` と `$$…$$` がコードのまま表示されていました。
今回から、本文中の数式も独立した行の数式も、アプリの色で描かれます
（[#3021](https://github.com/receptron/mulmoterminal/pull/3021)、
[#3017](https://github.com/receptron/mulmoterminal/issues/3017)）。

![全画面のプレビュー。本文中の数式と独立した行の積分が描かれ、値段の「$5」は文字のまま、下にコードブロックがある](../images/v10.2.0-preview-maths.png)

試し方: 数式を含む `.md` を全画面のファイル表示で開き、**Preview** を押します。`$5` のような値段や、コードの中は
そのままです。同じファイルを新しいタブで開いても数式が描かれます。

設定は不要です。詳しく: [機能リファレンス](features.html)

### エディタと Canvas 表示を並べる

Markdown のファイルでは、Files ペイン見出しの分割アイコン（横並びのボタン）で、Preview だけでなく **Canvas**
表示もエディタの横に並べられるようになりました。右側をどちらにするかは **Canvas** ボタンで決まります
（[#3020](https://github.com/receptron/mulmoterminal/pull/3020)、
[#3015](https://github.com/receptron/mulmoterminal/issues/3015)）。

![Files ペイン。ツリー、エディタの Markdown のソース、右に同じファイルの Canvas 表示が並ぶ](../images/v10.2.0-editor-beside-canvas.png)

試し方: Files ペインで `.md` を開き、分割アイコン → **Canvas** の順に押します。エディタで保存（Cmd+S）すると
右側が描き直されます。もう一度分割アイコンを押すと、Canvas 表示だけになります。

詳しく: [機能リファレンス](features.html)

### ShapeScript のファイルも Canvas 表示で開ける

Markdown・HTML・MulmoScript に加えて `.shape` も、Files ペインで開いて **Canvas** を押すと、ツリーの横に 3D
モデルとして表示されます
（[#3019](https://github.com/receptron/mulmoterminal/pull/3019)、
[#3016](https://github.com/receptron/mulmoterminal/issues/3016)）。

![Files ペインで .shape のファイルを Canvas 表示にし、3D モデルが出ている](../images/v10.2.0-canvas-shapescript.png)

設定は不要です。

## 画面の変化

- **Markdown の Canvas 表示中も、見出しに分割アイコンが残ります**（Edit/Preview は隠れます）。エディタを横に
  戻すためのボタンだからです。
- **全画面のプレビューの数式**が、`$…$` のままではなく描かれるようになりました。

## 見えない変化

- **数式はサーバー側で MathJax が描きます。** そのためプレビューは、これまでどおりスクリプトを使わないページの
  ままです。ページに届くのは MathJax 自身が書く要素と属性だけに絞っているので、数式からリンクやスタイル、
  HTML を持ち込むことはできません。
- ほかに必要な作業はありません。
