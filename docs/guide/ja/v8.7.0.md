# 8.7.0 — 結果を見せるアンケート、3D プリンタ用の STL、寝かせたセルが勝手に起きない

**8.7.0 時点（2026-10-03 リリース）のスナップショットです。** アプリが変わるにつれて古くなります。それは想定どおりで、
最新の説明は各節からリンクしているガイドにあります。

## 新機能

### 答えた人に結果を見せるアンケート

エージェントにアンケートを頼むときに、答えた人に結果を見せたいと伝えます。たとえば「講演のアンケートを作って。
答えた人には集計を見せて」（[#2884](https://github.com/receptron/mulmoterminal/pull/2884)）。新しいひな型
**survey-results** から作られます。

- 答えた人には、選択式の設問ごとに、各選択肢を選んだ人数と割合が見えます。答える前は設問だけが見えるので、
  結果に答えが引っ張られません。
- メールアドレス・名前・ご意見は、あなただけがアプリのメンバー用ページ（`/m/{slug}`）で読めます。そこには
  回答者ごとの答えも並びます。
- 数えるのは、あなたが用意した選択肢だけです。それ以外の値が送られてきても数えず、公開ページにも出しません。

結果を自分だけが読むアンケートが今も既定です。何も言わなければそちらになります。
[共有アプリ](shared-apps.html)を見てください。

### ShapeScript のモデルを 3D プリンタ用に書き出す

エージェントに「印刷用に STL で書き出して」と頼みます
（[#2876](https://github.com/receptron/mulmoterminal/pull/2876)）。ミリメートル単位・Z 軸が上・台に接した、
閉じた 1 つの立体として書き出し、ファイルの場所と、印刷できるかどうか（大きさ、離れた立体がいくつあるか、
接しているだけの部品や浮いている部品の警告）を答えます。設定は要りません。

## 画面の変化

- **設計図のヒアリングで、答える欄が広くなりました**
  （[#2883](https://github.com/receptron/mulmoterminal/pull/2883)）。自由記述の設問は、1 行の欄ではなく、
  大きさを変えられる複数行の欄になりました。文字も大きくなり、どの設問にも記入例が薄く出ます。アプリ名のように
  1 つの値を答える設問は 1 行のままです。[設計図](blueprints.html)を見てください。
- **`union`・`difference`・`intersection` で作った ShapeScript のモデルの見た目が少し変わります**
  （[#2876](https://github.com/receptron/mulmoterminal/pull/2876)）。どこで表示しても同じ仕組みで組み立てる
  ようになり、表面が閉じて、部品ごとの色が残ります。ほとんどのモデルで違いはごくわずかです。`union` の中の
  格子は、以前は時間切れで出ませんでしたが、プレビューできるようになりました。

## 見えない変化

- **寝かせたセルが、勝手に起きなくなりました**
  （[#2886](https://github.com/receptron/mulmoterminal/pull/2886)）。タブを閉じた、ノートパソコンがスリープした、
  サーバーを再起動した、などで接続が 30 秒以上切れると、つなぎ直した時点で、誰も入力していないのにセルが元の
  明るさに戻っていました。tmux の問い合わせに端末が自動で返した答えを、入力として数えていたためです。今は
  あなたが打ったときだけ起きます。直っているかの確かめ方: セルを寝かせ、タブを閉じて 1 分待ち、
  MulmoTerminal を開き直します。セルが薄いままなら直っています。なお Shift+F3 だけは、その自動の答えと
  まったく同じ形なので、押しても寝かせたセルは起きません。[機能リファレンス](features.html)を見てください。
- **ShapeScript が速く、丈夫になりました**（[#2876](https://github.com/receptron/mulmoterminal/pull/2876)）。
  形の組み合わせが 2〜3 倍速くなり、とても大きなモデルを画像にするときに失敗しなくなりました。
- **共有アプリの公開の行に、アカウントの id を載せなくなりました**
  （[#2879](https://github.com/receptron/mulmoterminal/pull/2879)、
  [#2880](https://github.com/receptron/mulmoterminal/pull/2880)）。`project-board` と `magazine` のひな型は、
  アカウントの id の代わりにアプリごとの仮名を使うので、ほかのアプリの同じ人の行とたどれません。すでに公開した
  アプリはそのまま動きます。変えたいときは作り直してください。
- 共有アプリの公開の仕組みと、そのほかのライブラリを更新しました
  （[#2877](https://github.com/receptron/mulmoterminal/pull/2877)、
  [#2878](https://github.com/receptron/mulmoterminal/pull/2878)、
  [#2887](https://github.com/receptron/mulmoterminal/pull/2887)、
  [#2888](https://github.com/receptron/mulmoterminal/pull/2888)）。

することはありません。
