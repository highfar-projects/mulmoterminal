# 10.8.0 — 忙しいターミナルの後ろに、自分の絵を出す

**10.8.0 時点（2026-10-17 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### 演出の絵に、自分の GIF・画像・動画を足す

しばらく忙しく動いているターミナルの後ろに、ときどき絵が出ます。爆弾、やかん、相撲の取組などです。
この 9 つの絵に、自分の絵を足せるようになりました
（[#3074](https://github.com/receptron/mulmoterminal/pull/3074)、
[#3073](https://github.com/receptron/mulmoterminal/issues/3073)）。
セッションごとに、組み込みの絵と自分の絵を合わせた中から 1 つが選ばれます。

設定画面には項目がありません。試すには:

1. MulmoTerminal を動かしているコンピューターのどこかにファイルを置きます。例: `~/Pictures/heat/fire.gif`
2. `~/.mulmoterminal/config.json` を開いて、次を足します。

   ```json
   { "playfulMedia": { "builtIn": false, "files": ["~/Pictures/heat/fire.gif"] } }
   ```

   `"builtIn": false` は組み込みの 9 つを外す指定です。これで、どのセッションでも自分のファイルが出ます。
   組み込みの絵と混ぜたくなったら、この指定を消してください。
3. 設定画面で **Reload config file** を押します。再起動は要りません。

- 項目は `{ "file": "...", "finale": "..." }` の形でも書けます。`finale` のファイルは、忙しかった
  セッションが落ち着いたときに 1 回だけ、はっきりした濃さで流れます。
- パスは `/` で始まる絶対パス（Windows ではドライブ文字も可）、自分のホームを表す `~/`、
  MulmoTerminal を起動したディレクトリを表す `./` のどれかで書きます。それ以外は無視されます。
- 画像は GIF・APNG・WebP・PNG・AVIF・SVG で 20 MB まで。動画は MP4・WebM で 50 MB まで、音は常に消えます。
- `"playfulEffects": "off"` にすれば、自分のファイルも含めて何も出ません。組み込みの絵を 1 つ名指ししたときも、
  これまでどおりその絵だけが出ます。

**うまくいったかの確かめ方:** ターミナルで時間のかかるビルドやテストを走らせます。後ろに自分の絵が出て、
忙しい時間が続くほど濃くなります。いつまでも出ないときは、MulmoTerminal を起動したターミナルを見てください。
使われなかったファイルは、名前と理由がそこに出ています。

詳しく: [忙しいターミナルの後ろに、自分の絵を出す](playful-media.html)（よい絵の作り方もここにあります）

## 画面の変化

`playfulMedia` を足さない限り、何も変わりません。これまでと同じ 9 つの絵が出ます。

## 見えない変化

- **Windows の CI で時々落ちていたテストを直しました**
  （[#3072](https://github.com/receptron/mulmoterminal/pull/3072)、
  [#3071](https://github.com/receptron/mulmoterminal/issues/3071)）。ファイル一覧の git の状態を確かめる
  テストが、上限を超えさせるために 2001 個のファイルを作っていて、遅い Windows の環境で時間切れになって
  いました。アプリの動きは変わりません。
- **重複していたコードを共通化しました**
  （[#3070](https://github.com/receptron/mulmoterminal/pull/3070)、
  [#3069](https://github.com/receptron/mulmoterminal/issues/3069)）。演出の絵の陰影、ドキュメント監視の
  開始と停止、型の定義 1 つです。画面は変わらず、何もする必要はありません。
