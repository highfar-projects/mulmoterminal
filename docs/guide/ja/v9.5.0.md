# 9.5.0 — ヒートの絵に UFO が加わり、静かな修正が二つ

**9.5.0（2026-10-08 リリース）時点のスナップショットです。** アプリが変わればこのページは古くなります。それは
想定どおりで、最新の説明は各節がリンクしているガイドにあります。

## 新機能

### Playful effects に UFO

ターミナルにときどき現れる絵に、UFO が加わりました。静かなあいだは浮かんで揺れ、マシンが熱くなるにつれて
光線を下ろして揺れが大きくなり、いちばん熱いときはふちのライトが赤くなり、最後は空へ飛び去ります
（[#2939](https://github.com/receptron/mulmoterminal/pull/2939)）。

- **オンにする操作はありません。** 既定は `"random"` で、セッションごとに絵が選ばれます。その候補に UFO が
  入りました。これまでと違う絵になるセッションがあります。
- **いつも UFO にしたい場合**は、設定に次を書いてタブを再読み込みします。

  ```json
  { "playfulEffects": "ufo" }
  ```

- **絵を出さないようにする場合**は、Settings → **Theme** のオン/オフのスイッチを使うか、
  `{ "playfulEffects": "off" }` と書きます。

## 画面の変化

- 新しい UFO の絵だけです（セッションがそれを選んだとき）。ほかの画面は変わっていません。

## 見えない変化

- **使用量のゲージが fullscreen を止めなくなりました。** Claude Code に `"tui": "fullscreen"` を設定しているのに、
  Claude Code の更新のあとでセルがいつのまにかインライン表示に戻っていたなら、原因はこれでした。使用量を
  読む裏のセッションが答えてすぐに終了され、Claude Code がそれを起動失敗と数えていました
  （[#2940](https://github.com/receptron/mulmoterminal/pull/2940)）。裏のセッションは従来の描画方式で
  起動するようになり、数えられません。新たに起こるぶんについては、することはありません。
  - **すでに起きていた場合**、Claude Code がそのログインの `.claude.json` に `fullscreenAutoDisabled` を書いています。
    このリリースでは消えません。fullscreen を戻したいときは、その項目を自分で削除してください。
- **止まった git の補助プロセスが、ワークツリーのステータスを固めなくなりました。** git が起動して
  動いたままになったツールがあると、ステータスの読み取りが待たされ、そのワークツリーへの後続の読み取りも
  その後ろで待っていました。読み取りは時間切れで終わり、残ったプロセスも一緒に止めます
  （[#2942](https://github.com/receptron/mulmoterminal/pull/2942)）。することはありません。
- ガイドのみの変更：token-rotation のページに、使用量の上限に当たったエージェントの再起動と、
  Token usage 画面の説明が入りました
  （[#2934](https://github.com/receptron/mulmoterminal/pull/2934)、
  [#2938](https://github.com/receptron/mulmoterminal/pull/2938)）。

詳しくは：[Token rotation](token-rotation.html)、[設定と config](config.html)。

**反映されたかの確かめ方：** 設定に `{ "playfulEffects": "ufo" }` を入れて、セッションが熱くなると UFO が出ます。
また、Claude Code を更新しても `fullscreenAutoDisabled` が新たに書かれなくなります。
