# 4.25.0 — Claude Code が無くても起動できる、スマホで codex / cursor / copilot の会話も読める

**4.25.0 時点のスナップショットです（2026-09-15 リリース）。** アプリが進めば古くなります — それは
織り込み済みで、生きているリファレンスは各節からリンクしているガイドのほうです。

知っておくことは 2 つ、手を動かす必要があるのは最初の 1 つだけです。

---

## Claude Code が入っていないマシンで動かす {#default-agent}

**何が困っていたか。** `npx mulmoterminal` は *"Claude Code CLI not found"* と言って終了していました。
Codex や GitHub Copilot CLI を使っていて Claude Code を入れていない環境では、アプリに一度も到達
できません — サーバ自体はどれも無くても起動するのに、です。

**既定は今も Claude Code です**、意図的に。ほぼすべての環境がそれで動いていますし、黙って別の
エージェントで起動すると「今どれが答えたのか」が分からなくなります。変わったのは、**別のものだと
宣言でき、起動時のチェックがその宣言に従う**ようになったことです。

**宣言のしかたは 2 つ。** フラグがファイルより優先され、フラグはディスクに書き戻されません:

```bash
npx mulmoterminal --agent codex
```

```json
// ~/.mulmoterminal/config.json
{ "defaultAgent": "codex" }
```

指定できるのはこのアプリがホストするエージェント名です: `claude` / `codex` / `antigravity` /
`grok` / `muse` / `copilot` / `cursor`。

**効いているかの見分け方。** 起動して最初の行を読んでください。宣言が無ければ Claude Code を探し、
あればそのエージェントのコマンドを探します。新しいセルの Agent Picker もそれで開きます。

**宣言したエージェントも「必須」です。** `codex` と宣言して `codex` が入っていなければ、起動は
止まってそう言います。自分で名指しした以上、それが無いマシンでは頼まれたことができません —
空のグリッドが出るより、理由が出るほうが親切です。

**変わらないもの**（保存したグリッドがある人にはこちらが重要です）:

| | |
|---|---|
| すでにあるセル | 変わりません。保存済みの Claude セルは Claude で立ち上がります。 |
| 既存セルの Agent Picker | 変わりません。 |
| **新しく**起動するとき | 宣言したエージェントで開きます。 |

この設定が決めるのは「**新しい**セッションが何で始まるか」です。画面上にあるものを一括で
付け替える機能ではありません。

**リファレンス:** 各エージェントに何ができるかは [エージェント](agents.html)、`config.json` の
残りは [設定ファイル](config.html) にあります。

## すでに Claude Code を使っている人にも当たっていたバグ {#claude-bin}

起動チェックは `PATH` 上の `claude` という**名前そのもの**を探していました。一方アプリ本体は
`CLAUDE_BIN` が指すものを実行します。つまり Claude Code が `PATH` の外にあって `CLAUDE_BIN` を
設定していた場合 — これは公式にサポートされた設定です — それでも起動を拒否され、しかも
**すでに持っているもの**をインストールしろと案内されていました。

**直っているかの見分け方。** 心当たりがあれば、`npx mulmoterminal@latest` がそのまま起動します。
設定することはありません。チェックが他の場所と同じように `CLAUDE_BIN` を読むようになりました。

## スマホの会話ビューが 4 エージェントを読めるようになりました {#transcript}

スマホでセルを開いたときの会話表示（生の画面ではなく、ターンの並び）が、claude に加えて
**codex** / **cursor** / **copilot** でも読めます。設定は要りません。

**何がどこまで見えるかはエージェントごとに違います。** これはその CLI が何を書き残すかで決まる
ので、無いものを探す前に知っておく価値があります:

| エージェント | 1 ターンに出るもの |
|---|---|
| claude | 質問・返答・走ったツール**とその結果** |
| codex | 同上 |
| cursor | 質問・返答・**どのツールが**走ったか — cursor はツールの結果を一切記録しません |
| copilot | 質問と返答のみ — copilot はツール呼び出しを一切記録しません |

**grok / muse / antigravity** は空の表示ではなく *"not supported"* と答えます。「このエージェントの
会話はここでは読めない」と「何も発言が無い」を区別できるようにするためです。未対応なのは、
形状を数えられる実セッションが 1 つも無かったからで、リーダーはエージェントごとに書く方針です
（CLI ごとに書き出すファイルが違うため）。

**リファレンス:** スマホ表示の残りは [スマホ](phone.html) にあります。

## このリリースのその他 {#rest}

以下はどれも設定不要です。

- **Chrome が GPU プロセスを再起動した後に文字が消えたままになる端末セル**が、描き直されるように
  なりました。セルから文字が消えて戻らない現象に心当たりがあれば、それです。
- **引用符つきで書かれた Windows の `PATH` エントリ**（`"C:\p\node_modules\.bin"` のような形）が、
  run script の注入ディレクトリを端末に持ち込ませないためのフィルタをすり抜けていました。
  入れた覚えのないツールをセルが引き継ぎ得る状態です。Windows のみ。
- cursor と copilot がそれぞれ兄弟ファイルから複製していたコードの共通化（重複コード警告 6 件を解消）。
- 依存パッケージの更新。
