# 9.1.0 — エージェントが Remotion の場面を自分で書く、スマホのターミナルからファイルをすぐ開く

**9.1.0 時点（2026-10-07 リリース）のスナップショットです。** アプリが変わるにつれて古くなります。
それは想定どおりで、いつも最新なのは各節からリンクしているガイドのほうです。

## 新機能

### エージェントが Remotion の場面を自分で書く

9.0.0 では、MulmoCast の動画の `remotion` の場面は、サーバーが裏で起動する別の Claude Code が書いていました。
これからは、**セルで話しているエージェント自身が場面を書けます**。MulmoCast のツールと一緒に Remotion の決まりが渡されているので、
会話しながら一緒に仕上げられます（[#2918](https://github.com/receptron/mulmoterminal/pull/2918)）。

試し方（9.0.0 と同じく、[MulmoCast の動画](mulmocast.html#remotion) の任意のパッケージが入っている必要があります）:

1. セルで頼みます。たとえば「短い MulmoCast の動画を作って。2 つ目のビートは remotion のコンポーネントとして自分で書いて、一緒に調整したい」。
2. エージェントがコンポーネントを書き（たいていは台本の隣の `.tsx` のファイル。直接書くこともあります）、ビートの `code` に入れます。
3. いつもどおり GUI パネルで動画にします。直したいところを言葉で伝えて、もう一度描画します。

- この方法では裏で何も書かれないので、サーバー側の Claude Code のログインを使わず、コードを見て直すこともできます。
- 描画がエラーで止まったら、そのエラーをエージェントに見せれば、コンポーネントを直します。
- 「Claude Code に任せて」と頼めば、これまでどおり 9.0.0 のやり方（`prompt`）でも作れます。

詳しくは [出来上がったコンポーネントを渡す](mulmocast.html#remotion-code) を見てください。

### スマホのターミナルから、そのプロジェクトのファイルを開く

プロジェクトがスマホにファイルを共有している（9.0.0 で入った `mobileFiles`）とき、**スマホのターミナルの画面にフォルダのボタンが出る**ようになりました。
押すと、そのプロジェクトのファイル一覧がすぐ開きます。ほかの区分を経由する必要はありません
（[#2916](https://github.com/receptron/mulmoterminal/pull/2916)）。

- ボタンが出るのは、そのターミナルのプロジェクトがファイルを共有しているときだけです。何も共有していないプロジェクトでは、
  外側のフォルダが共有していても、ボタンは出ません。
- ファイル一覧からは、戻るボタンで元のターミナルに戻れます。
- スマホのヘッダーのファイルのアイコンは、フィードの隣から、ターミナル側の課題の隣に移りました。

スマホの側は今の MulmoServer にすでに入っているので、そちらで更新するものはありません。
ファイルの共有のしかたは [スマホで開けるファイル](config.html#mobile-files) にあります。

## 画面の変化

- スマホのヘッダーのファイルのアイコンが、Collections の側ではなく、ターミナルの側（課題の隣）に移りました
  （[#2916](https://github.com/receptron/mulmoterminal/pull/2916)）。
- [MulmoCast の動画](mulmocast.html#remotion-code) のガイドは、mulmocast の説明を読ませる代わりに、エージェントに場面を書くよう頼めばよい、と案内するようになりました
  （[#2918](https://github.com/receptron/mulmoterminal/pull/2918)）。

## 見えない変化

- ライブラリの更新: mulmocast 2.15.0、MulmoCast のパネル 5.3.0、共通部分 5.11.0
  （[#2918](https://github.com/receptron/mulmoterminal/pull/2918)）。何もする必要はありません。
- エージェントが受け取る MulmoCast のツールの説明は長くなりました。Remotion の決まりを全部含むようになったためです。
- 上のスマホの変更を ChangeLog に記録しました（[#2917](https://github.com/receptron/mulmoterminal/pull/2917)）。

**入っているかの見分け方:** セルのエージェントに、Remotion の場面の `code` を自分で書けるかを聞いてみてください。
何も調べずに、`code` の形と決まりを説明できます。
