# 10.5.0 — エージェントが終わるとセルが閉じる、Antigravity が終わりを知らせる

**10.5.0 時点（2026-10-15 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### エージェントが自分で終わるとセルが閉じる

セルの中のエージェントが自分で終わったとき（`/exit` を打つ、Ctrl+C を 2 回押す、落ちる）、これまでは
`[session ended]` と出たままセルがグリッドに残っていました。エージェントが開いたセルはそうして積み上がって
いました。これからは、閉じるボタンを押したときと同じようにセルが閉じます
（[#3051](https://github.com/receptron/mulmoterminal/pull/3051)、
[#3049](https://github.com/receptron/mulmoterminal/issues/3049)）。

試し方：エージェントのセルを開き、起動したら `/exit` と打ちます。セルが消えます。

戻したくなったら、コマンドパレットで **Reopen** と打ちます。閉じたセルが並んでいて、エージェントのセルは
会話ごと戻ります。

次の三つは、わざと `[session ended]` の行を残したままにします。

- **エージェントが起動に失敗した**（起動してすぐ終わった）。何が起きたかを示すのはその行だけなので残します。
- **エージェントは動いているのに、ブラウザとのつながりが切れた。** ページを読み込み直すとつながり直します。
- **worktree のセル。** 閉じると worktree を残すか消すかを聞くので、黙って聞くことはしません。

グリッドを開いていない間にエージェントが立ち上げたセッションも同じです。見る前にエージェントが終わって
いたら、次にグリッドを開いても新しいセルとして戻ってきません
（[#3056](https://github.com/receptron/mulmoterminal/pull/3056)、
[#3055](https://github.com/receptron/mulmoterminal/issues/3055)）。

詳しくは [基本操作](basics.html)。

### Antigravity のセルに作業中の点が付き、終わると知らせる

Antigravity（`agy`）のセルで、ターンの間は作業中の点が付くようになりました。ターンが終わると注意の印が
付き、終了の音が鳴り、スマホに「終わった」の通知が届きます。Claude のセルと同じで、通知の設定もそのまま
効きます（[#3038](https://github.com/receptron/mulmoterminal/pull/3038)、
[#3034](https://github.com/receptron/mulmoterminal/issues/3034)）。

設定は要りません。MulmoTerminal がプロジェクトの `.agents/hooks.json` に `mulmoterminal` という名前の
フックを一つ足します。ご自身のフックはそのまま残り、`.git/info/exclude` で git の対象から外します。
「Antigravity が答えを待っている」を知らせる手段は、まだありません。

詳しくは [通知](notifications.html)。

### Canvas の MulmoScript が、外からの変更で描き直される

Files ペインの Canvas で MulmoScript を開いているとき、ファイルが外から書き換えられると（エディタ、`git`、
エージェントの編集）、Canvas が新しい中身で描き直されるようになりました。これまでは開き直すまで古い中身の
ままでした（[#3040](https://github.com/receptron/mulmoterminal/pull/3040)、
[#3014](https://github.com/receptron/mulmoterminal/issues/3014)）。Canvas の中で編集したときは、余計な
描き直しは起きません。

詳しくは [MulmoCast](mulmocast.html)。

### MulmoCast のしゃべるアバター：入れ方の案内と init での確認

MulmoCast では話し手をしゃべるアバターにできますが、必要な部品（`avatarscript`、`onnxruntime-node`）は
任意の依存で、MulmoTerminal は入れません。MulmoCast のガイドに書き方・入れ方・確かめ方の節を足し、
`npx mulmoterminal@latest init` は部品が見つかったかを **avatar** の行で示すようになりました
（[#3043](https://github.com/receptron/mulmoterminal/pull/3043)、
[#3042](https://github.com/receptron/mulmoterminal/issues/3042)）。

詳しくは [しゃべるアバター](mulmocast.html#avatar)。

### MulmoScript の新しい効果音と、ビートのプレビューの充実

MulmoCast 2.23 と MulmoScript プラグイン 5.5 になりました
（[#3037](https://github.com/receptron/mulmoterminal/pull/3037)、
[#3035](https://github.com/receptron/mulmoterminal/issues/3035)）。

- `soundEffects` で JingleScript 0.8 の効果音（`ding`、`door`、`dice` など）と `grandpiano` が使えます。
- ビートのプレビューが、背景・ブランディング・スクリプト付きの `html_tailwind` のビートを描きます。
- 静止画の生成に ffmpeg が要らなくなりました。ffmpeg が無いときの起動時の警告も、動画だけが使えない、
  という内容に変わりました（[#3036](https://github.com/receptron/mulmoterminal/pull/3036)）。

詳しくは [MulmoCast](mulmocast.html)。

### よくある疑問に短く答えるページ

検索されそうな疑問に答える短いページを 10 本足しました。Claude Code や Codex を並列で動かす方法、複数の
アカウントの使い分け、tmux・cmux・Claude Squad との違い、どのセルが待っているかの見分け方などです
（[#3052](https://github.com/receptron/mulmoterminal/pull/3052)）。

詳しくは [疑問に答える](../../answers/ja/)。

## 画面の変化

- **エージェントが終わるとセルが消えます。** これまでは `[session ended]` の行が出たまま残っていました。
  戻すときはコマンドパレットの **Reopen** を使います。
- **git の clone で動かしているときの更新の知らせ**が、`git pull origin <branch> && yarn install && yarn build`
  を実行してから再起動するよう案内するようになりました。これまでは `git pull` だけで、ブラウザ側と依存が
  古いまま知らせだけ消えていました（[#3045](https://github.com/receptron/mulmoterminal/pull/3045)、
  [#3044](https://github.com/receptron/mulmoterminal/issues/3044)）。

## 見えない変化

- **エージェントが、GUI の道具を一部だけ持たせたセッションを立ち上げられます。** `spawnBackgroundChat` が
  Claude のセッションで `guiGroups` を受け付け、その制限はつなぎ直し・再起動・再開のあとも続きます
  （[#3050](https://github.com/receptron/mulmoterminal/pull/3050)、
  [#3033](https://github.com/receptron/mulmoterminal/issues/3033)）。
- **別の `HOME` で起動した二つ目のサーバー**（スクリーンショットや試験用）は、自分専用の tmux サーバーと、
  ドロップしたファイルの置き場所を使うようになりました。これまでは一つ目のサーバーの使われていない
  セッションを終わらせたり、tmux の設定を変えたり、セッションにドロップしたファイルのコピーを消したり
  することがありました（[#3053](https://github.com/receptron/mulmoterminal/pull/3053)、
  [#3054](https://github.com/receptron/mulmoterminal/pull/3054)、
  [#3039](https://github.com/receptron/mulmoterminal/issues/3039)）。
- 依存の更新（[#3032](https://github.com/receptron/mulmoterminal/pull/3032)）、Chrome のキャッシュの共有による
  CI の高速化（[#3031](https://github.com/receptron/mulmoterminal/pull/3031)、
  [#3047](https://github.com/receptron/mulmoterminal/pull/3047)）、文書とコメントの言い回しの修正
  （[#3041](https://github.com/receptron/mulmoterminal/pull/3041)、
  [#3048](https://github.com/receptron/mulmoterminal/pull/3048)）。
- 何もする必要はありません。
