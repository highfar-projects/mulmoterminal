# 8.6.0 — セッションで動いているものを見る、共有アプリで見せるものを選ぶ

**8.6.0 時点（2026-10-03 リリース）のスナップショットです。** アプリが変わるにつれて古くなります。それは想定どおりで、
最新の説明は各節からリンクしているガイドにあります。

## 新機能

### セッションで動いているものと、消せる worktree を見る

**その他の機能** → **プロセス** を開きます（コマンドパレットで `Processes` と打っても開けます）
（[#2871](https://github.com/receptron/mulmoterminal/pull/2871)）。設定は要りません。

- **プロセス** のタブは、セッションのフォルダごとに、その下で動いているプロセスを並べます。PID、CPU、メモリ、
  動いている時間、コマンドです。忙しいものと、1 日以上動いているものには色が付きます。**終了** で止められます
  （先に確かめを出し、SIGTERM を送り、数秒たっても残っていれば SIGKILL を送ります）。勝手に止めることはありません。
- **worktree** のタブは、ターミナルを開いたことのあるフォルダの、管理下の worktree を並べます。それぞれに、消せない
  理由（コミットしていないファイル、元のブランチに入っていないコミット、そこで開いているターミナル）が出ます。
  理由が一つもないものには **削除** が出て、押すと消す前にもう一度すべて確かめます。自動では消しません。

画面を開いている間だけ読みます。詳しくは [基本編](basics.html)。

### 共有アプリで、訪問者に見せるものを選ぶ

共有アプリ（フォーム、申込み表、質問箱など）をエージェントに作ってもらうと、最初に「送られたものを公開ページで
訪問者に見せるか」を聞くようになりました
（[#2866](https://github.com/receptron/mulmoterminal/pull/2866)、
[#2873](https://github.com/receptron/mulmoterminal/pull/2873)）。答えは四つで、それぞれ別の形のアプリになります。

- **見せない** — 届いたものは自分だけが読みます。
- **選んだものだけ見せる** — 一件ずつ、MulmoServer の `/m/{slug}` の一覧で公開に切り替えるまで隠れています。
  新しい **質問箱（question-box）** のひな型がこの形です。誰でも質問でき、答えたものを公開します
  （[#2865](https://github.com/receptron/mulmoterminal/pull/2865)）。
- **集計だけ見せる** — 訪問者には、どの答えが何件かだけを見せ、名前やコメントは自分だけが読みます。新しい
  **集計（tally）** のひな型です（[#2873](https://github.com/receptron/mulmoterminal/pull/2873)）。
- **全部見せる** — 日程調整の表のように、全員の答えが並ぶこと自体が目的のもの。

プレビューも本番と同じ行を見せるようになりました。公開していない行が、試しているときの公開ページに出ることは
もうありません（[#2863](https://github.com/receptron/mulmoterminal/pull/2863)）。詳しくは [共有アプリ](shared-apps.html)。

## 画面の変化

- **その他の機能** に **プロセス** が加わりました（[#2871](https://github.com/receptron/mulmoterminal/pull/2871)）。
- 設計図のビルドの作業の一覧が、読み込みに失敗したときに何も出さないのではなく、そう伝えて **もう一度** の
  ボタンを出します（[#2859](https://github.com/receptron/mulmoterminal/pull/2859)）。

## 見えない変化

- **予約のひな型で、予約した人が届く場所で取り消せるようになりました**
  （[#2869](https://github.com/receptron/mulmoterminal/pull/2869)）。`meeting-room`・`salon`・`gym` は、取り消しを
  アプリの名簿に載った人しか開けないページに置いていたので、公開ページから予約した客は取り消せませんでした。
  これから作るアプリでは、`meeting-room` と `class-seats` は公開ページに「あなたの予約」と取り下げのボタンを出し、
  `salon` は取り消しを店で受け、`gym` は会員のページを開けるのは招待した会員だけだと案内します。
  **これらのひな型から前に公開したアプリ**は、何も変わりません（レコードも URL も設定もそのままです）。ただ、
  取り消しのページには、公開ページから予約した客は今も届きません。直すには、エージェントに新しいひな型の形へ
  直してもらって publish し直してください。それまでは、取り消しは連絡で受けるよう客に伝えてください。
- **誰でも読める行の id から、別のアプリの同じ人をたどれなくなりました**
  （[#2874](https://github.com/receptron/mulmoterminal/pull/2874)、
  [#2875](https://github.com/receptron/mulmoterminal/pull/2875)）。誰でも読める行は、アプリごとの仮名を id に
  使います。`schedule-poll` と `tally` のひな型がこれを使います。
- 共有アプリの公開の仕組み（`@receptron/sharedapp` 0.37〜0.39）を上げました。「選んだものだけ見せる」の宣言、
  送った人が自分で取り消せる期限を確かめ、予約の受付期間を動かせてしまう修正の宣言を断ります
  （[#2860](https://github.com/receptron/mulmoterminal/pull/2860)、
  [#2867](https://github.com/receptron/mulmoterminal/pull/2867)、
  [#2868](https://github.com/receptron/mulmoterminal/pull/2868)）。
- 設計図のビルドの作業の一覧で、同じ id の項目が二つあれば断ります
  （[#2859](https://github.com/receptron/mulmoterminal/pull/2859)）。

上の予約のアプリを公開していなければ、することはありません。
