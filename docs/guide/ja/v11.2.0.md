# 11.2.0 — 表を返す計算式

**11.2.0 時点（2026-10-22 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### 隣のセルまで埋める計算式

Canvas の表で、一つの計算式が一つの値ではなく表をまるごと返せるようになりました。答えは、Excel 365 と同じように、
その式の右と下のセルを埋めます（[#3157](https://github.com/receptron/mulmoterminal/pull/3157)）。

- `=SORT(UNIQUE(A2:A100))` は、値を一つずつ順に並べます。
- `=FILTER(A2:C100, C2:C100>1000)` は、条件に合う行だけを残します。
- `=GROUPBY(A2:A100, C2:C100, SUM)` は、グループごとに一行ずつ合計を出します。`PIVOTBY` は二つを掛け合わせます。
- `=Data!A1:C10` だけの式は、その範囲を写します。

埋める先のセルに何か入っていると、式は `#SPILL!` になります。そのセルを空けると埋まります。埋まったセルは、
ほかの計算式からも、エージェントが表から描くグラフからも、ふつうのセルと同じに読めます。たとえば:

> 地域ごとの売上の合計を、新しいタブに計算式で出して、そこからグラフにして。

と頼むと、データを直したときに表もグラフもついてきます。

詳しくは [表計算・グラフ・データ分析](spreadsheet.html#functions-you-can-use)。

### 関数が大きく増えた

表で使える関数に、`LET` と `LAMBDA`（`MAP`、`BYROW`、`BYCOL`、`REDUCE` も）、`LINEST` と `FREQUENCY`、
`FORECAST.ETS`、多くの検定（カイ二乗、分散分析、マン・ホイットニーなど）、`PERCENTILE` と `QUARTILE` の
`.EXC` 版、`RAND` が加わりました。分析のより多くの部分が、エージェントが一度だけ出した数ではなく、
計算し直される計算式のまま残ります。

詳しくは [使える関数](spreadsheet.html#functions-you-can-use)。

## 画面の変化

画面で動いたものはありません。表を返す計算式は、埋めたセルにふつうの値として見えます。

## 見えない変化

### 乱数が動かない

`RAND`、`RANDBETWEEN`、`RANDARRAY` は、Excel と違って計算し直すたびに同じ数を返します。エージェントとあなたが
同じ表を見るためです（[#3157](https://github.com/receptron/mulmoterminal/pull/3157)）。何もしなくて大丈夫です。

### ライブラリの更新

表の計算の部品と、いくつかのライブラリを新しくしました
（[#3157](https://github.com/receptron/mulmoterminal/pull/3157)、
[#3158](https://github.com/receptron/mulmoterminal/pull/3158)）。何もしなくて大丈夫です。
