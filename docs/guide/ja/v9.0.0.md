# 9.0.0 — MulmoCast の動画に Remotion の場面、スマホで開けるファイルの指定、1 分を超える動画の「失敗」表示の修正

**9.0.0 時点（2026-10-07 リリース）のスナップショットです。** アプリが変わるにつれて古くなります。
それは想定どおりで、いつも最新なのは各節からリンクしているガイドのほうです。

## 新機能

### MulmoCast の動画にアニメーションの場面（Remotion）

MulmoCast の動画のビートを、**`remotion` の場面**にできるようになりました。場面で見せたいものを文章で書くと、
Claude Code がそれを [Remotion](https://www.remotion.dev) のアニメーションとして書き、そのビートの動画になります。
動く文字、描かれていく線、3D などが使えます
（[#2906](https://github.com/receptron/mulmoterminal/pull/2906)、
[#2912](https://github.com/receptron/mulmoterminal/pull/2912)）。

[![GUI パネルから作った Remotion の場面二つ。「Remotion」の文字の周りに円が描かれ、続いて Script・Scene・Movie の三枚のカードが矢印でつながる。画像を押すと動画が再生されます。](../videos/v9.0.0-remotion-poster.png)](../videos/v9.0.0-remotion.mp4)

*このリリースで GUI パネルから作った二つの場面です。画像を押すと再生されます（10 秒、音声なし）。*

試し方:

1. **パッケージを一度だけ、ホームのフォルダに入れます。** 任意のパッケージなので、MulmoTerminal は入れません。
   コマンドは [MulmoCast の動画](mulmocast.html#remotion) のページにあります。
2. **確かめます:** `npx mulmoterminal@latest init` を実行すると、一覧に
   `✓ remotion — Remotion scenes in MulmoCast videos` と出ます。`optional` や `missing: …` と出たら、
   パッケージがまだ MulmoCast から見える場所にありません。
3. **名前を出して頼みます。** たとえば「2 つ目のビートを remotion の場面にして: タイトルが出て、その下に三つの箱が矢印でつながる」。
   あとはいつもどおり GUI パネルで動画にします。エージェントは、パッケージが入っているかどうかを知るすべがないので、
   頼まれたときだけこの場面を使います。

場面を書く Claude Code は、**MulmoTerminal のサーバー上で、いつものログインで**動き、1 つの場面で何回か呼ばれます。
1 場面に 1 分以上かかると考えてください。

**自分で場面を書く方法もあります。** 出来上がったアニメーションのファイルをビートに渡す（`code`）と、
Claude Code は一度も呼ばれず、そのまま描かれます
（[#2914](https://github.com/receptron/mulmoterminal/pull/2914)）。
書き方と守ることは [出来上がったコンポーネントを渡す](mulmocast.html#remotion-code) にあります。

### スマホで開けるファイルを指定する（MulmoTerminal の側）

プロジェクトごとに、スマホで一覧して開けるファイル（Markdown、HTML、PDF、画像）を決められるようになりました。
`.mulmoterminal.json` の `mobileFiles` に、フォルダとファイルの種類を書きます
（[#2913](https://github.com/receptron/mulmoterminal/pull/2913)）。

```json
{ "mobileFiles": { "dirs": ["output"], "extensions": ["md", "html", "pdf", "png"] } }
```

プロジェクトが書かないかぎり何も共有されず、共有されるのも書いたフォルダの中だけです。
設定 → ディレクトリ設定には **Phone files** として出ます。詳しくは
[スマホで開けるファイル](config.html#mobile-files) を見てください。

- **このリリースは MulmoTerminal の側の半分です。** ファイルを一覧して開くスマホの画面は、MulmoServer の更新で入ります
  （[receptron/mulmoserver#343](https://github.com/receptron/mulmoserver/issues/343)）。それまでスマホには何も出ません。
  今 `mobileFiles` を書いておいても害はなく、画面が入ればそのまま使えます。
- 画面が入ると、PDF・画像・大きなファイルは、あなたのアカウントだけが読める保存場所を通してスマホに渡され、1 時間後に消されます。

## 画面の変化

- **「Movie generation failed」が誤って出なくなりました。** 1 分を超えてかかる動画を作ると、実際にはまだ作っている途中なのに、
  赤い表示「Movie generation failed: signal is aborted without reason」が出ていました。そしてそのあと、出来上がった動画が
  失敗の表示の横に並んでいました。今は、出来上がるまで待ちます
  （[#2910](https://github.com/receptron/mulmoterminal/pull/2910)）。Remotion の場面はほぼ必ず 1 分を超えるので、それで見つかりました。
- ガイドに [MulmoCast の動画](mulmocast.html) のページが増えました（英語と日本語）。

## 見えない変化

- **カスタムビューのデータの取得が、指定したものだけになりました。** コレクションのカスタムビューがデータを求めると、
  指定した行（`ids`）と項目（`fields`）だけが返るようになりました。MulmoClaude ではもともとこうでした。
  大きなコレクションを、どちらも指定せずに求めると、全部ではなくエラーが返ります。エージェントが従う書き方の説明では、
  もともと指定するよう書かれています（[#2902](https://github.com/receptron/mulmoterminal/pull/2902)）。
- **Remotion が使うヘッドレスの Chrome は、MulmoTerminal を更新するたびにもう一度ダウンロードされます。**
  置き場所は MulmoTerminal 自身のフォルダで、約 90 MB、版ごとに一回です。何もする必要はありません
  （[#2914](https://github.com/receptron/mulmoterminal/pull/2914)）。
- ライブラリの更新: mulmocast 2.14.0、MulmoCast のパネル 5.1.0（エージェントに Remotion の場面を教えるもの）と、
  それが必要とする共通部分
  （[#2903](https://github.com/receptron/mulmoterminal/pull/2903)、
  [#2907](https://github.com/receptron/mulmoterminal/pull/2907)、
  [#2912](https://github.com/receptron/mulmoterminal/pull/2912)）。

**入っているかの見分け方:** `npx mulmoterminal@latest init` の一覧に、`remotion` の行が出ます。
