# 10.7.2 — 作業用のセッションを終えてセルも閉じる、macOS で worktree が軽くなる

**10.7.2 時点（2026-10-16 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### セッションを終わらせて、セルも閉じる

作業用のセッションを（`spawnBackgroundChat` で）立ち上げ、途中で入れ替えていくエージェントがあるなら、
セッションを終わらせるときにそのセルも消せるようになりました
（[#3068](https://github.com/receptron/mulmoterminal/pull/3068)、
[#3067](https://github.com/receptron/mulmoterminal/issues/3067)）。

```
curl -X POST http://localhost:$MULMOTERMINAL_PORT/api/session/<id>/close
```

返事は `terminate` と同じ `{"ok":true,"ended":true}` です。そのあとセルは、エージェントが `/exit` で
終わったときと同じように閉じ、Reopen に並びます。

これまでは `POST /api/session/:id/terminate` しかありませんでした。セッションは終わりますが、セルは
`[session ended]` のまま残り、閉じるボタンを押すまで消えませんでした。入れ替えるたびに、終わったセルが 1 つずつ増えていました。

- `terminate` では今もセルが残ります。これは意図したものです。セルの再起動やトークンの切り替えがこれを使い、
  同じセルにつなぎ直すためです。
- セルが閉じるかどうかは `/exit` と同じ規則で決まります。worktree のセルと、起動から約 2 秒以内に
  終えたセルは `[session ended]` のまま残ります。

**確かめ方:** セルを開いて数秒たったセッションに `close` を送ります。セルが `[session ended]` にならずに消えれば成功です。

詳しく: README の [Server API specification](https://github.com/receptron/mulmoterminal#server-api-specification)

## 画面の変化

画面には変化がありません。新しい呼び出し口はエージェントやスクリプト向けです。

## 見えない変化

- **Mac では、worktree が Time Machine でバックアップされなくなりました**
  （[#3066](https://github.com/receptron/mulmoterminal/pull/3066)、
  [#3059](https://github.com/receptron/mulmoterminal/issues/3059)）。worktree は 1 日に何度も作っては
  捨てるもので、依存を入れると 1 つで数万ファイルになります。MulmoTerminal は最初に worktree を作るときに、
  それらを置くフォルダ（`~/.mulmoterminal/worktrees`）を Time Machine の対象から外し、Spotlight にも
  索引しないよう印を付けます。何もする必要はありません。やはりバックアップしたい場合は
  `tmutil removeexclusion ~/.mulmoterminal/worktrees` を実行してください。
  詳しく: [worktree → どこに作られるか](worktree.html#location)
- **終わらせたセッションが、あとで拾われなくなりました。** どちらの呼び出し口で終えても、次にグリッドを開いたときに
  新しいセルとして出てくることはありません（[#3068](https://github.com/receptron/mulmoterminal/pull/3068)）。
