# 8.0.0 — ディレクトリの設定をすべて画面で。端末から一押しで開く

**8.0.0（2026-09-30 公開）時点のスナップショットです。** アプリが変わるにつれて古くなりますが、
それは想定どおりです。最新の説明は、各節から張ったガイドを見てください。

設定の必要はありません。以下はどれも、もう画面に出ているか、**設定**（右上の歯車）の中の操作です。
今までどおり `.mulmoterminal.json` を手やエージェントで書いても構いません。同じキーを書く道が増えただけです。

## 新機能

### ディレクトリの設定をフォームで変える

**設定 → ディレクトリ設定** でディレクトリを開くと、今効いている値の下に **ここで変える** が出ます
（[#2722](https://github.com/receptron/mulmoterminal/issues/2722)）。欄を離れる（色や選択肢は選ぶ）とすぐに保存され、
再起動しなくても開いている端末に効きます。各行の **全体に従う** で、そのキーをファイルから消せます。

![設定 → ディレクトリ設定 → ここで変える。名前・色・テーマ・フォントの欄が並んでいる](../images/v8.0.0-dir-settings.png)

変えられるものは次のとおりで、ファイルに書けるキーはすべて入っています。

- **見た目**（[#2733](https://github.com/receptron/mulmoterminal/pull/2733)）— 名前、ヘッダー・セル・バッジなど 7 つの色、端末のテーマ、
  文字の大きさ、フォント、グリッドの優先順。
- **状態の色と配色**（[#2737](https://github.com/receptron/mulmoterminal/pull/2737)）— セッションが動いているときのヘッダーの
  見せ方、状態ごとのヘッダーの色（全体の設定と同じ編集画面）、端末の配色（23 色）。
- **モデルと動かし方**（[#2742](https://github.com/receptron/mulmoterminal/pull/2742)）— このディレクトリのセッションが始まる
  モデル（全体の設定に登録し、使える状態のプロバイダから選ぶ）、終わりの要約の指示、追加で読み書きしてよいディレクトリ。
- **絵と音**（[#2743](https://github.com/receptron/mulmoterminal/pull/2743)）— アイコン（自動で探す / 出さない / 画像を指定）、
  端末の背景（画像・濃さ・合わせ方）、知らせる音（同梱の音か、ディレクトリのファイル。種類ごとにも）。
- **ヘッダー**（[#2746](https://github.com/receptron/mulmoterminal/pull/2746)）— ボタン・チップ・コマンドパレットの項目を、
  全体用と同じ編集画面で。ディレクトリのボタンは全体のボタンに足され、チップは組ごと置き換わります。
- **一覧と変数**（[#2750](https://github.com/receptron/mulmoterminal/pull/2750)）— Skill メニューに出す skill とその順番
  （このディレクトリで見える skill が候補に出ます）、Mulmo メニューのデッキ、作業ツリーごとの変数（ポートや一意な名前）。

保存は、変えたキーだけをファイルに書きます。フォームに無いキーも並び順もそのまま残り、書き換える前のファイルは
Files と同じ場所にバックアップされます。ファイルが JSON として壊れているときは書かずに、どのファイルを直せばよいかを出します。
詳しくは [設定のガイド](config.html#per-dir)。

### キーを「この checkout だけ」に移す

同じリポジトリを何か所かに clone しているとき、色や優先順をその checkout だけ変えたいことがあります。各行の
**この checkout だけにする** でキーを `.mulmoterminal.local.json` に移し、**共有に戻す** で `.mulmoterminal.json` に戻せます
（[#2750](https://github.com/receptron/mulmoterminal/pull/2750)）。値は書いてあるまま動き、local にあるキーには
*この checkout だけ* と印が付きます。

### 端末からそのディレクトリの設定を開く

端末のヘッダーのディレクトリを押して出るメニューに、**このディレクトリの設定** が加わりました
（[#2752](https://github.com/receptron/mulmoterminal/pull/2752)）。設定画面がディレクトリ設定で開き、そのディレクトリの行が
開いた状態になります。最近使ったディレクトリの一覧に無いディレクトリでも出ます。

### 過去のリリースノートを設定画面で

**設定 → リリースノート** に、今のバージョンまでの版が新しい順に並び、選ぶとその版のセットアップガイドが出ます
（[#2719](https://github.com/receptron/mulmoterminal/pull/2719)）。更新のあとに一度だけ出る「新しくなったこと」と同じページです。

### 設計図に二つの文書の作業

- **用語をそろえる**（[#2720](https://github.com/receptron/mulmoterminal/pull/2720)）— 文書が定義している用語、二度定義された用語、
  二通りに書かれた言葉を用語集にまとめ、頼めばそろえる書き方をフォルダの `chaff.yaml` に入れます。
- **文書のフォルダに chaff を入れる**（[#2740](https://github.com/receptron/mulmoterminal/pull/2740)）— 今ある指摘は棚に上げて
  （baseline）、新しい指摘だけが出るようにします。頼めば、プルリクエストの行に指摘を出す GitHub のワークフローも作ります。
  このワークフローは、フォルダが git リポジトリのときだけ選べます（[#2749](https://github.com/receptron/mulmoterminal/pull/2749)）。

詳しくは [設計図のガイド](blueprints.html)。

## 画面の変化

- 設定 → ディレクトリ設定の各ディレクトリに、上の **ここで変える** のフォームが出ます。
- 設定に **リリースノート** のタブが加わりました（ヘルプのまとまり）。
- 端末のパスメニューに **このディレクトリの設定** が加わりました。
- 設計図の新しい作業のフォームは、作業を先に聞き、土台（どこで動かすか）はその作業に候補が二つ以上あるときだけ聞きます
  （[#2741](https://github.com/receptron/mulmoterminal/pull/2741)）。文書の作業では土台を聞きません。
- 「このフォルダの規約」は、必要なファイル（`STYLE.md` や `chaff.yaml`）があるフォルダでだけ選べます
  （[#2744](https://github.com/receptron/mulmoterminal/pull/2744)）。
- 「文書を整える」の種類で、契約書・利用規約と規程・社内規則とマニュアルが別になりました
  （[#2747](https://github.com/receptron/mulmoterminal/pull/2747)）。自分の文書が無くても試せるよう、「例から始める」に
  「手順書を手順書として整える」が加わりました（[#2753](https://github.com/receptron/mulmoterminal/pull/2753)）。
- 共有アプリで、初めての人が止まりやすい二か所に次に押すものが出ます（[#2738](https://github.com/receptron/mulmoterminal/pull/2738)）。
  サインインしていなければツールバーの **Remote host** から **Connect** で Google にサインインする、と出ます。
  起動フォームの GUI ツールの切り替えには、開いている端末は再起動すると効く、と出ます。
- 共有アプリに新しいアドレスを招待すると、それがコミットされる `app.json` に入ることを知らせます
  （[#2736](https://github.com/receptron/mulmoterminal/pull/2736)）。

## 見えない変化

- ディレクトリの全体用の音 `sound` にも、同梱の音（`preset:<id>`）が書けるようになりました
  （[#2743](https://github.com/receptron/mulmoterminal/pull/2743)）。これまでは種類ごとの `sounds` でしか効かず、
  `sound` に書くと黙って無視されていました。ファイルのパスは今までどおりです。
- 全体のヘッダーのボタンとチップの保存は、ディレクトリのものと同じ処理を通るようになりました
  （[#2746](https://github.com/receptron/mulmoterminal/pull/2746)）。振る舞いは変わりません。
- 設計図の文書の作業は chaffjs 0.16 で動きます（[#2731](https://github.com/receptron/mulmoterminal/pull/2731)）。
- 読めないフォルダを「ファイルが無いフォルダ」と取り違えなくなりました（[#2745](https://github.com/receptron/mulmoterminal/pull/2745)）。
- 共有アプリの headless の試し動かしが、プレビューの枠が作り直されたときに止まらなくなりました
  （[#2730](https://github.com/receptron/mulmoterminal/pull/2730)）。
- ガイドに、コレクションからアプリにするページが加わりました（[#2718](https://github.com/receptron/mulmoterminal/pull/2718)）。
- FAQ に、Claude Code で会話をバックグラウンドに移すと新しいセッション id で続くこと、その見つけ方が加わりました
  （[#2739](https://github.com/receptron/mulmoterminal/pull/2739)）。

どれも、何もしなくてよい変化です。
