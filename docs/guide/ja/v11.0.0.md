# 11.0.0 — データに質問する

**11.0.0 時点（2026-10-19 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

このリリースで、会話だけでデータを分析する流れがそろいました。ファイルを渡して知りたいことを聞くと、
計算式の入った表と、表を追いかけるグラフが返ってきます。誰でもしそうな頼み方で 15 の分析を試し
（「このファイルを分析して」から「B のほうが本当に良い？」「解約しそうなのは誰？」まで）、見つかったことを直しました
（[#3113](https://github.com/receptron/mulmoterminal/issues/3113)）。

## 新機能

### 「分析して」でなく、質問でよい

「分析して」と言う必要はなくなりました。ファイルについて知りたいことを、そのまま聞いてください
（[#3114](https://github.com/receptron/mulmoterminal/pull/3114)）。

> ab_test.csv で、B のほうが良いと言っていい？

> data/sensor.csv はセンサーの 1 日分の値。おかしいところはある？

> data/monthly_sales.csv から来月の売上を予測して。

エージェントは言葉で答え、その答えの元になった表とグラフも出します。確かめたり、直したりできます。

詳しく: [頼み方](spreadsheet.html#analysis-how-to-ask)。

### Excel のファイル

Excel のファイル（`.xlsx`）も CSV と同じように使えます
（[#3114](https://github.com/receptron/mulmoterminal/pull/3114)）。エージェントは、ファイルにどんなシートがあって、
どれを読んだかを伝えます。大きな Excel のファイルは、スクリプトで集計します。

詳しく: [データを最初から最後まで分析する](spreadsheet.html#analysing-data-from-start-to-finish)。

### 表の関数が増えた

`ROW`、`COLUMN`、`ROWS`、`COLUMNS` が使えるようになりました
（[#3116](https://github.com/receptron/mulmoterminal/pull/3116)）。たとえば `=ROW()-1` で、データのシートの行に
番号を振れます。これまでは `#NAME?` と出ていました。

詳しく: [使える関数](spreadsheet.html#functions-you-can-use)。

## 画面の変化

### 表は、誤りのセルなしで届く

表の計算式が誤り（`#N/A`、`#VALUE!` など）になると、エージェントにどのセルかが伝わるようになり、
直してから「できた」と言うようになりました（[#3114](https://github.com/receptron/mulmoterminal/pull/3114)）。
直す間に、表が 2 回出ることがあります。わざと残す誤り（検索で見つからない場合など）は、そう伝えます。

## 見えない変化

### 月や文字を正しく読む

することはありません。前に作った表にも、新しい表にも効きます
（[#3116](https://github.com/receptron/mulmoterminal/pull/3116)）。

- **`2025-01` と書いた月が、数の 2025 として読まれていました。** その列で月ごとに合計すると、どの月にも 1 年分の
  合計が入り、しかも誤りとしては出ませんでした。今は `2025-01` は文字として読まれ、月ごとの合計になります。
- **カンマを含む文字（`Tokyo, Japan`）が 0 と読まれていました。** 今はその文字のままです。
- **日本語の名前のシートを、`'` で囲まずに参照できます**（`=基準!B1`）。
- 互いを参照するシートが正しく速く計算され、`$A$2:$C$10` のような範囲の検索も動きます
  （[#3114](https://github.com/receptron/mulmoterminal/pull/3114)）。

**直ったかの確かめ方:** 表の A1 に `Tokyo, Japan`、B1 に `=LEN(A1)` と書きます。12 と出れば直っています（前は 1）。

Excel と違うところが一つ残っています。`2025-01` は日付にはなりません。日付を受け取る関数（`YEAR(A1)`）は
`#VALUE!` を返し、自分でセルに `2025-01` と打つと引き算として読まれます。書いたとおりに残すには、
セルの編集で種類を「**文字列**」にしてください。
