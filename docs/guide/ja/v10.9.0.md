# 10.9.0 — Canvas に表計算、フォルダをギャラリーで

**10.9.0 時点（2026-10-19 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### 計算式が生きている表を Canvas に出す

エージェントが、ターミナルの横の Canvas に**表計算**を出せるようになりました
（[#3078](https://github.com/receptron/mulmoterminal/pull/3078)、
[#3076](https://github.com/receptron/mulmoterminal/issues/3076)）。合計・平均・割合は本物の計算式なので、
セルの数字を直すと、それに関わるところがその場で計算し直されます。1 つの表に複数のシートをタブで持てて、
右上の **Excel** で `.xlsx` ファイルとして保存できます。

![左にシェルのセルで CSV、右の Canvas に同じデータの表](../images/spreadsheet-overview.png)

試すには、ふつうの言葉で頼みます。「今月の数字を表にして」「グラフにして」。

- **ワークスペース**では、Claude・Codex・Copilot のセルでそのまま使えます。
- **プロジェクトのディレクトリ**では、ランチャーの MCP の切り替えで **Canvas** をオンにしてから、
  そこで新しいセッションを始めます。

数字を直したら、エージェントに「表を読み直して」と頼みます。直した内容が伝わります。

詳しく: [会話しながら表計算・グラフ・データ分析](spreadsheet.html)。使える関数の一覧もあります。

### CSV を分析する: `/mulmoterminal-data-analysis`

CSV や TSV を最初から最後まで分析する同梱スキルが入りました
（[#3093](https://github.com/receptron/mulmoterminal/pull/3093)、
[#3091](https://github.com/receptron/mulmoterminal/issues/3091)）。

> /mulmoterminal-data-analysis orders.csv

列と空の値を確かめ、要約の統計を出し、データに合った表とグラフを見せて、どこに保存したかを伝えます。
計算に使ったスクリプトは `<workspace>/artifacts/analysis/` に置かれ、あなたのリポジトリには書きません。
スキルの名前を言わなくても、「orders.csv を分析して」でたいてい足ります。

表を直してから読み直しを頼むと、計算し直した表は**新しい**表として出ます
（[#3095](https://github.com/receptron/mulmoterminal/pull/3095)）。そのあとは新しい表のほうを直してください。

詳しく: [CSV を最初から最後まで分析する](spreadsheet.html#what-to-ask-for)。

### Files ペインでフォルダをギャラリーとして見る

Files のツリーでフォルダを右クリックし、**Open as gallery** を選びます
（[#3081](https://github.com/receptron/mulmoterminal/pull/3081)、
[#3079](https://github.com/receptron/mulmoterminal/issues/3079)）。そのフォルダの画像・動画・音声・PDF が、
名前順（`2.png` が `10.png` より前）にまとめて並びます。

![ターミナルの横の Files ペインで、フォルダをギャラリーとして表示。画像・動画・音声がタイルで並ぶ](../images/v10.9.0-files-gallery.png)

- 動画と音声はタイルの中で再生できます。別のものを再生すると、前のものは止まります。
- タイルをクリックすると大きく表示します。**←** / **→** で前後のファイルへ、**Esc** で一覧に戻り、
  もう一度 **Esc** でギャラリーを閉じます。
- 並ぶのはそのフォルダ直下のファイルだけで、サブフォルダの中は含みません。ファイルが多いときは
  最初の 1 ページだけ並び、**Show more** で続きを出します。
- ファイルを開くと、ギャラリーは閉じます。

詳しく: [機能リファレンス](features.html)。

## 画面の変化

- **プレビューと Canvas が、次のファイルに引き継がれます**
  （[#3077](https://github.com/receptron/mulmoterminal/pull/3077)、
  [#3075](https://github.com/receptron/mulmoterminal/issues/3075)）。セルの横の Files ペインで、Markdown を
  プレビューで読んでから別のファイルを開くと、エディタではなくプレビューで開くようになりました。
  セッションごとに覚えていて、読み込み直しても残ります。ファイルごとに別の表示を選んであれば、そちらが
  優先されます。全画面の Files は変わりません。

## 見えない変化

- **画面専用の保存を、モデルが道具の呼び出しで行えなくしました**
  （[#3082](https://github.com/receptron/mulmoterminal/pull/3082)、
  [#3080](https://github.com/receptron/mulmoterminal/issues/3080)）。画面の HTML・ShapeScript・表計算からの
  保存は今までどおりです。何もする必要はありません。
- **プロジェクトのディレクトリのエージェントが、表やグラフの保存先を読めるようになりました**
  （[#3085](https://github.com/receptron/mulmoterminal/pull/3085)、
  [#3084](https://github.com/receptron/mulmoterminal/issues/3084)）。道具の返事が完全なパスを返します。
  以前はプロジェクトのセルで「表を読んで合計を教えて」が失敗していました。
- **表計算のプラグインを 4.0.2 にしました**
  （[#3089](https://github.com/receptron/mulmoterminal/pull/3089)）。`=LOG10(100)` が `#ERROR!` ではなく
  `2` になります。
- **ガイドに表計算とグラフのページができました**
  （[#3088](https://github.com/receptron/mulmoterminal/pull/3088)、
  [#3086](https://github.com/receptron/mulmoterminal/issues/3086)）。
- **Files ペインのコードを小さく分けました**
  （[#3087](https://github.com/receptron/mulmoterminal/pull/3087)、
  [#3083](https://github.com/receptron/mulmoterminal/issues/3083)）。見た目も動きも変わりません。
