# 11.1.0 — フォルダを一目で、グラフを増やし、使用量ゲージを控えめに

**11.1.0 時点（2026-10-21 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### ファイル画面でフォルダを見る

拡大したターミナルの隣にファイル画面を開くと、ファイルを開く前の右側にファイルを選ぶよう促す案内ではなく
フォルダの中身が出るようになりました（[#3131](https://github.com/receptron/mulmoterminal/pull/3131)）。
左のツリーでフォルダをクリックすると、そのフォルダが出ます。

- **一覧**は、フォルダを先にしてファイルの大きさとともに並べます。フォルダの行をクリックするとその中へ、
  ファイルの行をクリックするとそのファイルを開きます（**Cmd**/**Ctrl**+クリックで別のタブに開きます）。
- **ギャラリー**は、画像・動画・音声・PDF をタイルで並べます。
- **サブフォルダも含める**にすると、少し下の階層まで、フォルダごとに見出しを付けて出します。
- **一つ上のフォルダへ**で上のフォルダに移ります。

移るたびに、左のツリーもそのフォルダまで開いて、その行を目立たせます
（[#3135](https://github.com/receptron/mulmoterminal/pull/3135)、
[#3139](https://github.com/receptron/mulmoterminal/pull/3139)）。一覧かギャラリーかは、このブラウザで覚えています。

詳しくは [機能リファレンス](features.html) の「ターミナルの隣でファイルを編集する」。

### 描けるグラフが増えた

グラフを頼むと、エージェントが描けるものが増えました
（[#3128](https://github.com/receptron/mulmoterminal/pull/3128)、
[#3140](https://github.com/receptron/mulmoterminal/pull/3140)、
[#3145](https://github.com/receptron/mulmoterminal/pull/3145)、
[#3154](https://github.com/receptron/mulmoterminal/pull/3154)）。

- 日本地図・世界地図の塗り分け（都道府県名や国名は日本語でも通ります）
- 点のまとまり分けと、列ごとの箱ひげ図
- 散布図に重ねる曲線とヒストグラム。どちらも表から描くので、表を直すと追いかけます
- 値の大きさで文字の大きさを変えるワードクラウド
- パレート図、ウォーターフォール、二つの値の軸、相関行列、カレンダー状のヒートマップ、3D

グラフのカードは **SVG** と **CSV** でも保存でき、暗いテーマに合わせて表示され、場所があれば横に並びます
（狭い Canvas では一列に一つ。[#3151](https://github.com/receptron/mulmoterminal/pull/3151)）。
描けないグラフがあると、その理由がエージェントに返り、見せる前に直します。

データ分析のスキルもこれを使います
（[#3129](https://github.com/receptron/mulmoterminal/pull/3129)、
[#3143](https://github.com/receptron/mulmoterminal/pull/3143)、
[#3147](https://github.com/receptron/mulmoterminal/pull/3147)、
[#3150](https://github.com/receptron/mulmoterminal/pull/3150)）。たとえば:

> data/stores.csv を分析して。似ている店をまとめて、都道府県別の売上を地図で見せて。

詳しくは [表計算・グラフ・データ分析](spreadsheet.html#analysing-data-from-start-to-finish)。

### 使用量ゲージを止める、測る間隔を延ばす

グリッドの上に出る Claude と Codex の使用枠は、隠れた `claude` を起動して小さな問い合わせを 1 回することで
測っています。おおよそ 10 分ごとで、その問い合わせも測っている当の枠を使います。これを控えめにできるように
なりました（[#3155](https://github.com/receptron/mulmoterminal/pull/3155)）。

1. **設定** → **グリッドのヘッダー表示** を開きます。
2. **使用量ゲージ** のチェックを外すと、ゲージが消えて何も測らなくなります。
3. または **−** / **+** で、Claude を測る間隔を 2〜60 分の間で決めます（既定は 10 分）。

すぐに効きます。`~/.mulmoterminal/config.json` では `usageGauge` と `usageProbeIntervalMinutes` です。

詳しくは [設定](config.html#settings-modal)。

### Windows: psmux でセルが再起動を越えて残る

Windows に [psmux](https://github.com/psmux/psmux) を入れると、MulmoTerminal はほかの OS の tmux と同じように
使います。サーバを再起動しても、セルは動き続けます
（[#3133](https://github.com/receptron/mulmoterminal/pull/3133)）。

```
winget install -e --id marlocarlo.psmux
```

psmux は 3.4.0 以降を使ってください。それより古いと、貼り付けた後の Enter と Esc 二回が効かず、
サーバのログにその旨が出ます。psmux が無くてもこれまでどおり動きます。セルが再起動を越えて残らないだけです。

詳しくは [はじめに、ステップ 3](getting-started.html#step3)。

## 画面の変化

### ファイル画面の JSON

`.json` のファイルは、プレビューで字下げと色付きの JSON として出ます。Canvas で開く選択肢は MulmoScript
（一番外側に `$mulmocast` がある JSON）にだけ出るので、ふつうの JSON で「MulmoScript として正しくない」と
出ることはなくなりました（[#3141](https://github.com/receptron/mulmoterminal/pull/3141)）。

### 左右に並べた表示が残る

ファイル画面で編集とプレビューを左右に並べていると、ほかのセルから戻ってきても並んだままです
（[#3132](https://github.com/receptron/mulmoterminal/pull/3132)）。

### 狭い Canvas のグラフ

狭い Canvas で一列に二つ詰め込まれていたグラフのカードが、一列に一つで、題名も全部見えるようになりました
（[#3151](https://github.com/receptron/mulmoterminal/pull/3151)）。

## 見えない変化

### シンボリックリンクのフォルダで「.」だけの会話が溜まらない

作業フォルダがシンボリックリンク（Windows ではネットワーク共有へのリンクがよくあります）だと、使用量を測るたびに
「.」とだけ答えた会話が残り、`claude --resume` の一覧に溜まっていました
（[#3156](https://github.com/receptron/mulmoterminal/pull/3156)）。何もしなくて大丈夫です。もう残らず、
すでに溜まった分も MulmoTerminal の起動時に消えます。

**直ったかの確かめ方:** MulmoTerminal を起動してから、作業フォルダで `claude --resume` を開きます。
10 分より前の「reply with the single character: .」の会話が消えています。

### 表計算の日付

`YEAR` や `DATEDIF` などの日付の関数が、`2025-01-15`、`2025-01`、`2025年1月` のような文字を日付として読み、
`TEXT(A2,"yyyy-mm")` で日付を `2025-01` の形にできるようになりました。小文字や日本語で書いた日付の表示形式も
正しく出ます（[#3118](https://github.com/receptron/mulmoterminal/pull/3118)、
[#3119](https://github.com/receptron/mulmoterminal/pull/3119)）。何もしなくて大丈夫です。

### GitLab のホストやリポジトリの一覧を変えたとき

設定画面でセルフホストの GitLab やリポジトリを足すと、すぐに効きます。`config.json` を手で直したときは、
設定の **Reload config file** を押せば再起動は要りません。ガイドと、知らないホストのときのメッセージが
そう言うようになりました（[#3126](https://github.com/receptron/mulmoterminal/pull/3126)、
[#3127](https://github.com/receptron/mulmoterminal/pull/3127)、
[#3130](https://github.com/receptron/mulmoterminal/pull/3130)）。
