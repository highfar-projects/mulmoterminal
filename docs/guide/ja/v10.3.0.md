# 10.3.0 — エージェントがファイルを見せ、確認を頼む

**10.3.0 時点のスナップショット（2026-10-12 リリース）。** アプリが変わるにつれて古くなります。それは想定どおりで、
最新の情報は各節からリンクしているガイドにあります。

## 新機能

### エージェントが端末の横のペインでファイルを開く

エージェントが、自分のセルの Files ペインでファイルを開けるようになりました。エディタ、Preview、Canvas 表示、
エディタと Canvas 表示の横並びのどれでも、行を指定しても開けます。何かを変えた直後に、説明する代わりに
変更そのものを見せられます（[#3023](https://github.com/receptron/mulmoterminal/pull/3023)、
[#3022](https://github.com/receptron/mulmoterminal/issues/3022)）。

![端末の横の Files ペインに、エージェントが頼んだ design.md が Canvas 表示で開いている](../images/v10.3.0-show-in-pane.png)

試し方: ワークスペースで、またはランチャーで **Canvas** をオンにしたプロジェクトのディレクトリで、Claude の
**新しい**セッションを始めます。「README.md を Canvas 表示で見せて」と頼むと、端末の横にペインが開いてファイルが出ます。

### エージェントが確認を頼む

エージェントは端末の上に**確認項目**を出すこともできます。各項目には見るべきことが書いてあり、ワンクリックで
そのファイルを開けます。項目ごとに **OK** か **NG** を付け、おかしいところがあればメモを書いて **Send** を押すと、
答えが一行で端末に入力されます。エージェントはそれを次のメッセージとして読み、NG を直します
（[#3023](https://github.com/receptron/mulmoterminal/pull/3023)）。

![端末の上の確認カード。3 項目のうち 1 つが OK、1 つが NG でメモ付き。ペインには項目 2 の HTML ページが開いている](../images/v10.3.0-request-check.png)

試し方: エージェントが変更を終えたら「動くか確認する項目を出して」と頼みます。拡大したセルの右下にカードが出ます。
たたむと下の端末が見え、閉じると送らずにしまえます。

エージェントのセルが画面に出ていないときは、画面は何も変わりません。ファイルや確認は、そのセルを拡大するまで待っています。
何も拡大していなければ、エージェントのセルが自動で拡大されます。

二つの道具の詳しい働き、頼み方、制限:
[エージェントが右ペインを操作する](pane-tools.html)。

## 画面の変化

- エージェントが頼むと、拡大したセルの右下に**確認カード**が出ることがあります。
- エージェントがファイルを見せるとき、**Files ペインが自動で開きます**。

## 見えない変化

- 二つの道具は **Canvas** の道具（`render` グループ）に入っています。Canvas の道具が使えていたところでは使えます。
  更新前から動いていたセッションには無いので、新しく始めてください。
- エージェントが操作できるのは自分のセルのペインだけで、作業ディレクトリの中のファイルだけです。
- 何もする必要はありません。
