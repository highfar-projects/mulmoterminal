# 5.0.0 — 画面ではなく、会話を読む

**5.0.0 時点のスナップショットです（2026-09-18 リリース）。** アプリが進めば古くなります — それは
織り込み済みで、生きているリファレンスは各節からリンクしているガイドのほうです。

**設定は要りません。** ボタンがあるので、上げればそこにあります:

```bash
npx mulmoterminal@latest
```

**壊れるものもありません。** メジャー番号はこのリリースが**何のためのものか**を示しているだけで、
設定キーの意味が変わったわけでも、パスが動いたわけでもありません。

---

## 何ができるか {#the-feature}

Claude のセルはターミナルの **alt screen** で動くので、スクロールバックが残りません。つまり画面の
上に流れた会話は「スクロールで戻れないところにある」のではなく、**無い**。1 時間前に何と言われたか
を知る手段が、もう一度聞くことしかありませんでした。

セルを拡大して、ヘッダーの**吹き出し**ボタンを押すと、ターミナルが退いて、そのセッション自身の
会話がそこに出ます。

![ターミナルの場所に出た会話ペイン。You の枠、畳まれた Tools の枠、Markdown としてレンダリングされたエージェントの返答](../images/v5.0.0-conversation-pane.png)

画面のキャプチャではありません。エージェント自身の transcript を読むので、ANSI の残骸は無く、
再描画で消えた部分もあり、ターンの切れ目は「行の折り返し位置」ではなく**エージェントが記録した
切れ目**です。

**話者ごとに枠。** 自分が聞いたことと、エージェントが答えたことが別の枠に入り、それぞれ名前が
付きます。1 ターンの中で何度も交代する（聞く → 答える → 3 つ実行する → また答える）ので、行を
並べるのではなく、その交代に合わせて枠を切ってあります。

**返答は Markdown としてレンダリング。** 見出し・リスト・表・コードブロックが、エージェントが書いた
文書として描かれます。**自分が打ったもの**は打ったままです — `#` で始まる行は `#` で始まる行で
あって、見出しではありません。

**ツールは畳んであります。** 1 ターンの `Bash` / `Read` / `Edit` はかさの大半を占めるのに、読み返し
に来た理由ではまず無いので、連続したぶんは 1 行に畳んで「何が走ったか」（`Bash · Read · Edit`）
だけ出ます。出力が見たいときにクリックしてください。

## どこまで遡れるか {#scrolling-back}

**上にスクロールすると 1 ページずつ、そのセッションの最初のターンまで遡ります。**ページが上に
足されても読んでいた位置は保たれるので、飛ばされません。

開いた瞬間にも、読める量になるまで足してから渡します: 最新のターンがたまたま小さいセッション
（一言の指示、キューされて返答が付かなかったプロンプト）だと、実体のあるターンが 1 つ上に落ちた
状態で開くことになるためです。スクロールは「さらに前へ」行くためのもので、会話を探すためのもの
ではありません。

**意図的にやらないこと**が 2 つあります:

- **走っているターンを追いません。** 開いた時点のスナップショットです。ライブビューは隣の
  ターミナルで、読み返している最中に動くペインは、その 1 つの仕事に対して邪魔にしかなりません。
  ヘッダーの**再読み込み**で最新を取り直せます。
- **他のセッションには跨りません。** 1 セッションを先頭まで。別の会話は、そのセッションから開いて
  ください。

## 読めるエージェント {#agents}

| エージェント | 会話ペイン |
|---|---|
| Claude | 対応 |
| Codex | 対応 |
| Cursor | 対応 — ツールの**結果**は出ません（cursor が記録しないため） |
| Copilot | 対応 — ツール行そのものが出ません（copilot が記録しないため） |
| Grok・Muse・Antigravity | 未対応 |

最後の行のエージェントは黙って失敗しません。「このエージェントの会話は、まだここで読めない場所に
ある」と出ます。**shell** セルには会話が無く、これからも無いので、開く意味のあるペインがそもそも
ありません。

`/clear` で終えた会話も、終えた会話を見せるのではなく、その旨を出します。

生きているリファレンスは [機能一覧](features.html)。

## 入ったかどうかの見分け方 {#how-to-tell}

セルを拡大して、ヘッダーの outbox とマージ矢印の間に吹き出しボタンがあれば 5.0.0 です。

## このリリースのその他 {#also}

どれも設定は要りません。

- **返答内のリンクが新しいタブで開きます。** これまではアプリごと遷移してしまい、動いている
  ターミナル・開いているペイン・保存していないエディタのバッファまで道連れで、戻る手段もありません
  でした。
- **返答内のリモート画像を取りに行きません。** `<img>` は画面に出た瞬間に取りに行くので、返答に
  混ざっていれば「誰がいつペインを開いたか」が相手に渡っていました — 返答を書くのは web や他人の
  リポジトリを読むエージェントです。URL はリンクになり、開くと決めたときだけ取りに行きます。この
  マシンの中で完結する画像は今までどおり表示されます。
- **読み込みに失敗したら、そう言います。** 遡っている途中で読めなかったとき、「先頭に到達しました」
  ではなく「この前のターンが読めませんでした」と出ます。
