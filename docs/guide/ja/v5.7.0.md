# 5.7.0 — 履歴表示から戻れるように、スマホの一覧が中身で分かるように

**5.7.0 時点のスナップショットです（2026-09-24 リリース）。** アプリが進めば内容は古くなります。
それは前提で、各節からリンクしている「生きているガイド」が常に最新です。

設定することはありません。どちらも 5.7.0 を起動した時点で有効です。

## copy-mode に入ったセルが、そのことを表示する

**有効にする操作はありません。**

**シェル**や **Codex** のセルをマウスホイールで遡ったり、セル内をドラッグしたりすると、tmux は
そのペインを **copy-mode** にします。これまでは何も表示されませんでした。キーはプログラムではなく
tmux に届くので、`mode-keys vi` では `h` `j` `k` `l` がカーソルを動かし、ほかの文字は消えていました。

今はセルのヘッダーの下に帯が出ます。

> 履歴を表示中 — 入力は端末に届きません。q で戻ります。

隣に **「入力に戻る」** ボタンがあり、ボタンでも `q` でも戻れます。戻るときにプログラムへは何も送らず、
端末にフォーカスが戻るので、そのまま打ち込めます。

**入っているかの確かめ方:** シェルのセルでホイールを上に回します。帯が出て、「入力に戻る」を押すと
消えます。

**しないこと:** ホイールで copy-mode に入ること自体は止めません。copy-mode の中のキー（移動・選択・
コピー）もそのままです。アプリの外（別の `tmux attach`）から copy-mode に入った場合は、そのセルに
次に打ち込んだときに帯が出ます。

## スマホのターミナル一覧が、各セッションの中身を名乗る

**有効にする操作はありません。**

セッションメモも AI タイトルも無い実行中のセッションは、これまでスマホのターミナル一覧に **UUID**
で出ていました。今は会話から名付けます — エージェントが付けたタイトル、直近のプロンプト、最初に
頼んだこと。まだ会話の無い新しいセッションは、`mulmoterminal · codex` のように、どこで動いているかで
表します。ID が出るのは、ほかに手がかりが何も無いときだけです。

`/clear` したセッションが、終わらせた会話の名前で出ることはありません。

セッションメモは引き続き何よりも優先され、一覧に出るセッションも変わりません。

**入っているかの確かめ方:** 新しいターミナルを開き、タイトルが付く前に最初のプロンプトを送ります。
スマホの一覧では、その行に ID ではなくそのプロンプトが出ます。

**スマホ側でこれからのもの:** ホストは各行の直近のプロンプトも送るようになりました。それを見出しの
下に出すこと、ディレクトリを途中で切れた絶対パスではなくプロジェクト名で見せることは
[mulmoserver#287](https://github.com/receptron/mulmoserver/issues/287) で扱います。
