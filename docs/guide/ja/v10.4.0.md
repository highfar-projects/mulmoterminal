# 10.4.0 — タイル表示のままペインを開く、セルの外のファイルをタブで開く

**10.4.0 時点のスナップショット（2026-10-13 リリース）。** アプリが変わるにつれて古くなります。それは想定どおりで、
最新の情報は各節からリンクしているガイドにあります。

## 新機能

### セルを拡大せずにペインを開く

セルの**履歴**・**道具**メニューのペイン（プロンプト・会話・道具・キャンバス・コレクション、パスメニューの
「アプリでファイルを見る」で開く Files）は、これまで先にセルを拡大する必要がありました。並べて表示しているセルでは
「セルを拡大すると横に開けます」と灰色になっていました。いまは**グリッドの右に**開き、タイルはすべて見えたままです
（[#3029](https://github.com/receptron/mulmoterminal/pull/3029)、
[#3027](https://github.com/receptron/mulmoterminal/issues/3027)）。

![並べて表示した 2 つのターミナルと、グリッドの右に開いた道具ペイン](../images/v10.4.0-tiled-pane.png)

試し方: どのセルも拡大していない状態で、タイルの**道具**メニュー（ヘッダーのスパナ）から**道具**を選びます。
右にペインが出ます。境目をドラッグすると幅を変えられます。

こう動きます:

- ペインが映すのは、**メニューで開いたタイル**です。別のタイルをクリックしたり入力したりしても動きません。
  別のタイルのメニューから開くと、そのタイルに移ります。
- 同じタイルで同じ項目をもう一度選ぶと閉じます。
- セルを拡大するとペインはその横についてきて、元に戻すとタイルの横に戻ります。
- タイル表示では、会話ペインも含めて全幅にはなりません。全幅は拡大したセルの横でだけ使えます。
- ペインのタイルがグリッドの別のページにあるときは、そのページに戻るまでペインは隠れます。開いていた内容は、
  保存していない編集も含めてそのまま残ります。
- タイルの横に Files ペインが出ていて、ファイルがそのタイルのディレクトリにあれば、ターミナルでクリックした
  ファイルパスはここでも Files ペインに開きます。

今までどおり拡大してから開くもの: エージェントの描画、エージェントからの質問、エージェントがペインに出す
ファイルや確認項目。これらは、拡大したセルの横でだけ自分で開きます。

詳しくは [Claude Code を複数同時に動かす](basics.html)。

### セルの外にある動画・画像・PDF・音声・ページがタブで開く

ターミナルに出た、**セルのディレクトリの外**にある動画・画像・PDF・音声・HTML ページのパスをクリックすると、
これまでは `{"error":"cwd is not an active session directory"}` と書かれたタブが開いていました。いまはその
タブにファイルが開きます
（[#3028](https://github.com/receptron/mulmoterminal/pull/3028)、
[#3024](https://github.com/receptron/mulmoterminal/issues/3024)）。

試し方: どのターミナルでもよいので、別の場所にある画像の絶対パスを出して（`echo ~/Pictures/photo.png`）
クリックします。

- タブに出せるのは**そのファイルだけ**です。隣の画像を参照している HTML ページは、その画像なしで表示されます。
- ファイルが無くなっていれば、タブにそう出ます。
- セルの外の Markdown・JSON・表・ソースは、今までどおりの開き方です。

詳しくは [機能リファレンス](features.html)。

### 確認項目を閉じるとエージェントに伝わる

エージェントが出した確認項目（10.3.0 で追加）を、**Send** ではなく × で閉じると、ターミナルに
`Check "<title>" was closed without answers.` の 1 行が入るようになりました。答えを待つように言われていた
エージェントが、来ないメッセージを待ち続けることはもうありません
（[#3026](https://github.com/receptron/mulmoterminal/pull/3026)、
[#3025](https://github.com/receptron/mulmoterminal/issues/3025)）。

詳しくは [エージェントが右ペインを操作する](pane-tools.html)。

## 画面の変化

- **タイルの履歴・道具メニュー**で、ペインが「セルを拡大すると横に開けます」と灰色になることはなくなりました。
  どの項目も選べます。
- ペインを横に開いている間は、そのぶん**グリッドが狭く**なります。

## 見えない変化

- コマンドパレットの **Files ペイン**と `pane-*` のキーも、先に拡大せず、タイル表示ならグリッドの右に開きます。
- セルの外のファイルは、クリックしたときだけ作られる、そのファイル 1 つ用のリンクで配信されます。サーバーを
  再起動するまで有効です。
- 必要な操作はありません。
