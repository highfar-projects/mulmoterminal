# 8.2.0 — 設計図の工程が止まりにくくなり、閉じたセルを開き直せる

**8.2.0（2026-10-01 公開）時点のスナップショットです。** アプリが変わるにつれて古くなりますが、
それは想定どおりです。最新の説明は、各節から張ったガイドを見てください。

## 新機能

### 設計図の工程が、止まる前に自分で直しにいく

工程の終わりの確かめが通らないと、これまでは 3 回やり直して止まり、「もう一度」を押すしかありませんでした。
押しても、同じ情報で同じやり直しをするだけでした。8.2.0 では次のように変わります。設定は要りません。

- やり直しのとき、エージェントは確かめのスクリプトそのものを読んで、何を求められているかを確かめます
  （[#2812](https://github.com/receptron/mulmoterminal/pull/2812)）。確かめのほうは書き換えません。
  「アクションを機能にする」の確かめは、読み取ったテストの名前と数え方も出すようになりました。
- 3 回続けて通らないと、そこからは **直しの試み** になります（[#2813](https://github.com/receptron/mulmoterminal/pull/2813)）。
  それまでの失敗をすべて並べて見比べ、なぜ毎回通らないのかを突き止めてから直します。止まるまでの回数は 5 回になりました。
- 別のビルドが同じフォルダで作業していて待っていた工程は、そのビルドが止まると（終わるか、あなたを待つようになると）
  **自動で続きを始めます**（[#2814](https://github.com/receptron/mulmoterminal/pull/2814)）。MulmoTerminal を起動し直したときも同じです。
- 質問への答えのファイルが書けなかったときも、止まらずに自動でやり直します（[#2814](https://github.com/receptron/mulmoterminal/pull/2814)）。

**前の版で 3 回で止まったビルドも、続きから直しにいきます。** 8.2.0 に上げて MulmoTerminal を起動すると、
まだ回数が残っているので、直しの試みとして再開します。

Claude Code がフォルダを信頼していないときだけは、人にしか答えられないので、これまでどおり止まります
（[作業用フォルダを信頼しておく](blueprints.html#trust)）。

### 閉じたセルを開き直す

うっかり閉じたセルを、コマンドパレットから開き直せます（[#2802](https://github.com/receptron/mulmoterminal/pull/2802)）。

1. コマンドパレットを開きます。
2. 最近閉じたセルが「閉じたセルを開く: <名前>」として、いつ閉じたかとディレクトリつきで並んでいます。名前やディレクトリで探せます。
3. 選ぶと、今のターミナルの隣に開きます。エージェントは会話を再開し、シェルは同じディレクトリで新しく開きます（前の画面は戻りません）。

キーに割り当てたいときは、`keymap` に `terminal-reopen`（最後に閉じたターミナルを開き直す）を足します。
既定では何のキーにも割り当てていません。ヘッダーのボタンにもできます。
詳しくは [キーボードショートカット](config.html#keymap)。覚えておく一覧はこのブラウザの中にだけあります。

### 共有アプリのひな形が二つ増えた

共有アプリに、次の二つの型が加わりました（[#2804](https://github.com/receptron/mulmoterminal/pull/2804)）。欲しいものを自分の言葉で頼めば、エージェントが型を選びます。

- **定員つきの教室**（class-seats）— 申し込む人には「あと何席」だけが見え、誰が申し込んだかは見えません。取り消しは受付（あなた）がします。
- **日程調整**（schedule-poll）— 候補の日ごとに参加できるかを一人一つ答え、あとから自分の答えを直せます。締め切りを過ぎると答えも直しも止まります。

詳しくは [共有アプリ](shared-apps.html)。

## 画面の変化

- 設計図の工程が回数を使い切って止まったときは、「自動で 5 回直そうとしましたが、まだ確かめが通りません。…」と、
  何回試したかと「もう一度」で何が起きるかが判定の結果の上に出ます（[#2814](https://github.com/receptron/mulmoterminal/pull/2814)）。
- 別のビルドを待っている工程の説明は、「止まったら自動で続きを始めます」に変わりました（[#2814](https://github.com/receptron/mulmoterminal/pull/2814)）。
- ツールバーの右側のアイコンが、まとまりごとに並び直りました（[#2801](https://github.com/receptron/mulmoterminal/pull/2801)）。
  コマンドパレットと設定はいつも右端にあり、出たり消えたりするボタンが他のアイコンを動かしません。
  新しい版の知らせは、文字のボタンから小さな点つきのアイコンになりました。押すと、これまでどおり更新のコマンドが出ます。

## 見えない変化

- 文書の作業は chaffjs 0.18 で動きます（[#2806](https://github.com/receptron/mulmoterminal/pull/2806)）。
  用語の指摘が、使うべき書き方を名指しするようになりました。
- ShapeScript のプラグインが receptron/gui-chat-plugins に移り（[gui-chat-plugins#13](https://github.com/receptron/gui-chat-plugins/pull/13)）、取り寄せ先が `@gui-chat-plugin/shapescript` に変わりました（[#2810](https://github.com/receptron/mulmoterminal/pull/2810)）。
  道具と画面は同じです。
- 依存するパッケージを新しくしました（[#2798](https://github.com/receptron/mulmoterminal/pull/2798)）。

どれも、何もしなくてよい変化です。
