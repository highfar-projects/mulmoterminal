# 7.1.0 — Files ペインが履歴を残し、Markdown の見出しを出し、エージェントに行を指せる

**7.1.0（2026-09-30 公開）時点のスナップショットです。** アプリが変わるにつれて古くなりますが、
それは想定どおりです。最新の説明は、各節から張ったガイドを見てください。

設定は要りません。任意なのは、新しい操作 `focus-mode` と `files-insert-selection` へのキーの割り当てと、
上段の検索欄を出すことだけです。どちらも下にあります。

## Files ペイン: 履歴、見出し、表、エージェントに渡す行

これまでどおり、セルを拡大して Files ペイン（パスのメニューの **Browse files in the app**）を開きます。

**履歴。** ペインはこれまでもファイルの写しを残していました（開いたとき、上書きする前、衝突で読み直すときに
捨てる編集中の内容）が、それを読み返す手段がありませんでした。ペインの上部の **履歴** が、新しい順に一覧します。

- **比べる** は、最後のコミットの代わりにその版との違いを印で示し、消えた行も見せます。版の名前と
  **戻す**・比べるのをやめるボタンを持つ帯が出ます。
- **戻す** は、その版を**編集として**エディタに入れます。取り消せて、ファイルは未保存の印が付き、
  保存すると置き換えた側の内容も版として残ります。

![Files ペインで、開いているファイルを残っている版と比べているところ。消えた行と新しい行、戻す・比べるのをやめるの帯](../images/v7.1.0-history-compare.png)

**見出し**（Markdown ファイル）。上部の **見出し** ボタン（リストのアイコン）が、ファイルの見出しを
階層ごとに字下げして出し、今いる見出しに印を付けます。選ぶとそこへ移ります。エディタならその行へ、
Preview ならその見出しへ。

![Markdown ファイルの見出しの一覧。階層ごとに字下げされている](../images/v7.1.0-outline.png)

**CSV / TSV を表で。** `.csv` と `.tsv` にも Markdown と同じように **Preview** が付き、アプリの配色で表として描きます。

**選んだ行をエージェントに指す。** 行を選んでペイン上部の **@** を押すと、`@path#L12-18`（一行なら `#L12`、
何も選んでいなければパスだけ）がセルのプロンプトに送信せずに入ります。エージェントはディスク上の
ファイルを読むので、未保存の編集は先に保存されます。キー割り当ての操作 `files-insert-selection` でも同じことができます
（既定のキーはありません）。

最新のガイド: [ターミナルの隣でファイルを編集する](features.html#ターミナルの隣でファイルを編集する)

## ターミナルでパスをクリックする

- **`path:line` はその行で開く。** `src/a.ts:42`、`src/a.ts:42:7`（gcc・eslint・`grep -n`）、
  `src/a.ts(12,5)`（tsc）が一つのリンクになり、ファイルはその位置にカーソルを置いて開きます。
- **HTML のパスはページとして開く。** Files ペインを出していないとき、エージェントが出力した `.html` の
  パスをクリックするとソースが出ていましたが、描画したページが開くようになりました。

## 集中モード: ブラウザのタブ操作キーを自分のキー割り当てに

ブラウザは `Cmd`/`Ctrl`+`W`・`T`・`N` を自分で使うので、それに割り当てたキーは効きません。新しい操作
**`focus-mode`** はアプリを全画面にし、Keyboard Lock を持つブラウザ（Chrome・Edge・Arc、`https` か
`localhost` のとき）では、**そのタブ操作キーだけ**を自分のキー割り当てに回します。抜けるのはいつもどおり `Esc` です。
画面の下に、キーを受け取れたかどうか、受け取れなかったならその理由が出ます。

`keymap` に割り当てるか（既定のキーはありません）、ターミナルの画面のコマンドパレットで **集中モード** を選びます。

```json
{ "keymap": { "focus-mode": "Ctrl+Shift+f" } }
```

**ブラウザが取ってしまうキーを設定画面が教えるようになりました。** 設定 → キーボードショートカットで、
使っている環境でブラウザが取ってしまう割り当てには **効かない** の印が付き（ツールチップに回避策があります）、
一覧の下の注記がそのキーを挙げます。サーバー起動時の確認でも警告します。

最新のガイド: [キーボードショートカット（`keymap`）](config.html#keymap)

## 上段の中央に検索欄（任意）

設定 → **グリッドのヘッダー表示** で **検索欄**（`paletteSearchBox`）をオンにすると、どの画面でも上段に
コマンドパレットを開く欄が出ます。既定はオフで、**Commands** ボタンとパレットのキーはそのままです。
狭いウィンドウでは欄が縮み、タブレットより狭い幅では出ません。

![上段の中央にある検索欄](../images/v7.1.0-search-box.png)

## 修正: Markdown Preview からのメッセージ

Files ペインは、自分が求めた Markdown Preview の文書からのメッセージだけを聞くようになりました。
Markdown ファイルが自分のプレビュー枠を移動させ、プレビューのふりをしてペインにメッセージを送れたためです。
プレビューごとに専用の合言葉を持たせ、それの無いメッセージは捨てます。設定は要りません。

## 設計図

- **Cloudflare の土台。** Worker が API を出し、D1 がデータを持ち、同じ Worker が Vue の画面を出します。
  公開する前に `wrangler dev` で手元で確かめます。**コレクションから** もこの土台で動き、記録を D1 に、
  ファイルを R2 に移します。
- **ビルドの一覧は、あなたを待っているものを先に出します**: あなた待ち（承認・回答・停止）、進行中、完了の順です。
- **文書**: 英語の文書では事実の表示が `$320` や `(Thursday)` と書きます。曜日の食い違いは、文書の書き方で
  実際の曜日を記録します。AM/PM が一度だけの時間の範囲は両方の時刻を保ちます。合計の差を正しい向きで述べます。
  契約についての答えは、契約の書き方で段落を名指しします。文体が有効にする規則はすべて効くところを見せます。
  文書のパックは chaff 0.14 を使います。
- **小さな修正**: 新しいビルドの画面は、ディスク上のパックの並び順によらず、再び文書の土台で開きます。
  フォルダを信頼する間に残したフォームは再読み込みしても消えません。ビルドは actions のチェックが要る
  TypeScript 6 のままにします。
