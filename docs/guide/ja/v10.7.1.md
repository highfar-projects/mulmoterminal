# 10.7.1 — 契約の週の枠を少し残しておける

**10.7.1 時点（2026-10-16 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

この版は **トークンのローテーション**（複数の Claude の契約を MulmoTerminal が順番に使う機能）を使っている人向けです。
使っていなければ、何も変わりません。

## 新機能

### 契約の週の枠を少し残しておく

トークンのローテーションは、どの契約も週の枠がほぼなくなる（98%）まで使います。そのうち 1 つを
MulmoTerminal の外（スマートフォン、Claude.ai、別のマシンなど）でも使っているなら、その契約の週の枠を
一部残すように指定できるようになりました
（[#3065](https://github.com/receptron/mulmoterminal/pull/3065)、
[#3064](https://github.com/receptron/mulmoterminal/issues/3064)）。

1. `~/.mulmoterminal/config.json` を開く。
2. `tokenRotation` → `tokens` の中から、その契約の項目を探し、残したい割合（パーセント）を
   `"reserveWeeklyPercent"` で足す。

   ```json
   { "id": "personal", "label": "Personal", "email": "me@example.com", "keychain": "mulmoterminal-token-personal", "reserveWeeklyPercent": 5 }
   ```

3. 設定画面の **「設定ファイルを読み直す」** を押す（再起動は要りません）。

`5` なら、その契約は週の枠が 95% に達した時点で使い切ったものとして扱います。

- その契約では新しいセッションを始めません。
- その契約で動いているセッションは、いまのターンが終わったところで別の契約へ移り、同じ会話を続けます。
  セルにはその旨が 1 行出ます。
- ほかの契約がすべて使い切っていても、残した 5% には手を付けません。

0 より大きく 99 以下の値が使えます。それ以外の値は無視され、残さない設定として動きます。
この項目がない契約は、これまでどおりです。

**効いているかの確かめ方:** 「その他の機能」→「トークンの使用量」に契約ごとの週の枠の残りが出ます。
残す設定をした契約がその線に達すると、新しいセルはほかの契約で開きます。

詳しくは [トークンのローテーション → 週の枠を少し残しておく](token-rotation.html#keep-week-back)。

## 画面の変化

ありません。新しい設定は設定ファイルの中だけです。

## 見えない変化
