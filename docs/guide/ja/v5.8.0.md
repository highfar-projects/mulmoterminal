# 5.8.0 — セルごとに別の契約（ベータ）と、起動できないエージェントの表示

**5.8.0 時点（2026-09-24 リリース）のスナップショットです。** アプリが進むにつれて古くなりますが、それは想定どおりです。最新の情報は、各節からリンクしているガイドにあります。

設定が要るのは、使いたい人だけが設定する `accounts`（**ベータ**）の一つだけです。それ以外は、5.8.0 を起動した時点で有効です。

## セルを 2 つ目の契約で動かす（ベータ）

**設定が必要です** — Claude Code や Codex の契約を複数持っている場合だけです。

> **ベータ版です。** 自動テストでは確かめていますが、実際の作業で一日使うような確かめ方はまだしていません。何も設定しなければ何も変わりません。アカウントのセルで様子がおかしいときは報告してください。

`~/.mulmoterminal/config.json` に `accounts` の一覧を足し、再起動してタブを再読み込みします。

```json
{
  "accounts": [
    { "id": "work", "label": "仕事", "agent": "claude", "home": "~/.claude-work" }
  ]
}
```

すると、空のセルの起動画面で、モデルの下に **ACCOUNT** の選択欄が出ます。アカウントを選んで起動します。ディレクトリが新しいときは、そのセルで一度 `/login` します。セルのヘッダーにはアカウント名が出て、そのセッションは再開してもそのアカウントのままです。ツールバーには、いつものログインの横に、そのアカウントの **5h / 7d** の使用枠が出ます。

新しい Claude のアカウントでは、使用枠のチェックがまず Claude Code の信頼プロンプトで止まることが多く、ツールバーに `仕事 n/a` と出ます。解消するには、そのアカウントで**ワークスペース**にセルを起動し、プロンプトを一度承認します。

**入っているかの確かめ方:** 設定 → **モデルとバックエンド** の *2 つ目以降の契約* にアカウントが並び、そのエージェントの起動画面に ACCOUNT の選択欄が出ます。

ガイド: [複数の契約を並べて使う](accounts.html)（手順の全体）、[設定 → accounts](config.html#accounts)（キーの一覧）。

## `CLAUDE_CONFIG_DIR` と `CODEX_HOME` に従うようになった

**設定は不要です。**

`CLAUDE_CONFIG_DIR` を設定して MulmoTerminal を起動すると、これまではセッション一覧・再開・プロンプトの履歴・同梱スキルが `~/.claude` を見に行ってしまい、空になっていました。`CODEX_HOME` を設定したときの Codex の使用枠ゲージも同じく空でした。どちらも、エージェントが実際に書き込む場所から読むようになりました。

**直っているかの確かめ方:** `CLAUDE_CONFIG_DIR` を設定した状態で、作業したことのあるディレクトリの再開一覧にセッションが並びます。

## 起動できないエージェントは薄く表示される

**設定は不要です。**

新しいセルの Agent Picker で、コマンドが入っていないエージェント（または `<AGENT>_BIN` の指定先が存在しないもの）が**薄く表示**されるようになりました。それでも選ぶと理由が出て、開発元のインストール手順へのリンクが出ます。既定のエージェントが見つからないときに CLI が出すメッセージにも、同じリンクが出ます。インストールの有無はサーバーの起動時に一度だけ調べるので、エージェントを入れたら再起動してください。

**入っているかの確かめ方:** 入れていないエージェントが、ピッカーで薄く表示されます。

ガイド: [どの coding agent を使うか](agents.html)。

## 再開した issue のセッションが元のエージェントで開く

**設定は不要です。**

worktree にセッションが残っている issue で作業を始めると、そのセッションを再開しますが、これまでは常に Claude として開いていました。そこにあった Codex の会話が、新しい Claude のセッションに置き換わることがありました。今は、起動したときのエージェントで開きます。

**直っているかの確かめ方:** issue で作業を始め、その worktree で Codex のセッションを動かし、セルを閉じてから同じ issue をもう一度始めます。開くセルが Codex のセルになります。
