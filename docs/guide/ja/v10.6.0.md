# 10.6.0 — Codex と Copilot のワーカーも GUI の道具を絞れる

**10.6.0 時点（2026-10-15 公開）の記録です。** アプリが進むにつれて古くなります。それは想定どおりで、
最新の説明は各節のリンク先のガイドにあります。

## 新機能

### Codex や Copilot のワーカーを、GUI の道具の一部だけに絞る

あるエージェントが別のエージェントを立ち上げる使い方のための機能です（取りまとめ役が、それぞれのフォルダで
動くワーカーに仕事を渡す、など）。10.5.0 から、取りまとめ役は **Claude** のワーカーを MulmoTerminal の
GUI の道具の一部だけで立ち上げられるようになっていました。今回、**Codex** と **Copilot** のワーカーでも
同じことができるようになりました（[#3057](https://github.com/receptron/mulmoterminal/pull/3057)、
[#3033](https://github.com/receptron/mulmoterminal/issues/3033)）。

GUI の道具は 4 つのグループに分かれています。`render`（グラフ・フォーム・文書・あなたへの質問）、`data`、
`media`、`external` です。取りまとめ役は `spawnBackgroundChat` を呼ぶとき、ワーカーが使ってよいグループを
`guiGroups` に並べます。

```json
{ "message": "落ちているテストを直して", "agent": "codex", "guiGroups": ["data"] }
```

- `guiGroups` を書かなければ、これまでどおり GUI の道具をすべて持ちます。
- `[]` にすると、GUI の道具を何も持ちません。
- グループを並べると、そのグループの道具だけを持ちます。ほかのセッションを立ち上げることはできません。
  `render` を入れない限り、自分のセルからあなたに質問することもできません。

この制限は、セルを開き直しても、サーバーを再起動しても、会話を再開しても続きます。Codex では、再開の一覧から
開き直した場合も同じです（一覧では Codex の会話が Codex 自身の id で並んでいます）。

Antigravity・Grok・Cursor・Muse で `guiGroups` を指定すると、すべての道具を持つワーカーを立ち上げる代わりに、
理由を添えて断ります。これらのエージェントは、同じフォルダのすべてのセッションが共有するファイルから道具を
読むためです。

うまくいったかの確かめ方: ワーカーのセルを開いて道具の一覧を見ます。指定したグループの道具だけが並びます。

これは道具を **差し出さない** 仕組みで、隔離された環境ではありません。シェルを使えるワーカーが意図すれば、
HTTP で MulmoTerminal を直接呼べます。また Copilot のワーカーは、どの Copilot のセッションとも同じく、
Copilot 自身の組み込みの道具とあなた自身の MCP サーバーを事前に承認したままです。

参考: [README](https://github.com/receptron/mulmoterminal/blob/main/README.md) の API の表の
`POST /api/plugin/:toolName` の行、[機能一覧](feature-list.html)。

## 画面の変化

- 画面に変化はありません。制限した Codex や Copilot のワーカーの道具の一覧には、Claude のワーカーと同じく、
  そのグループの道具だけが並びます。

## 見えない変化

- **10.5.0 で書き漏れた注意（HOME をいつも別の場所にして MulmoTerminal を動かしている人だけ）。**
  10.5.0 から、別の `HOME` で動くサーバーは自分専用の tmux サーバーと、ドロップしたファイル用の自分専用の
  フォルダを使います。そのため、本来のホームで動くサーバーを乱さなくなりました
  （[#3053](https://github.com/receptron/mulmoterminal/pull/3053)）。いつもその使い方をしている場合、
  10.5.0 以降で初めて起動したときに、アップグレード前の端末にはつなぎ直せません。会話そのものは
  いつもどおり再開できます。古い端末は、終わらせるまで裏で動き続けます。

  ```sh
  tmux -L mulmoterminal kill-server
  ```

  これを実行するのは、本来のホームで MulmoTerminal を一度も動かさない場合だけにしてください。本来のホームでは、
  この名前の tmux サーバーが使われています。`HOME` を変えていなければ、この注意は関係なく、何もする必要は
  ありません。
- 再起動の直後に開いた Codex や Copilot のセルは、自分のセッションが制限されているかが分かるまで待つように
  なりました。以前は、短いあいだ全部の道具を持って立ち上がることがありました（#3057）。
