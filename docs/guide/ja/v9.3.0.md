# 9.3.0 — 同時に開いたセルを、複数の契約へ散らす

**9.3.0（2026-10-08 リリース）時点のスナップショットです。** アプリが変わればこのページは古くなります。それは
想定どおりで、最新の説明は各節がリンクしているガイドにあります。

## 新機能

このリリースで新しく入れるスイッチはありません。[トークンローテーション](token-rotation.html)を使っている方への
変更が 1 つだけあります（下の「画面の変化」）。

## 画面の変化

- **同時に開いたセルが、別々の契約で始まるようになりました。** これまでは、複数の契約を登録していても、
  セルを続けて何個か開くと、全部が同じ契約に行くことがありました。使用量の数字は読み直したときにしか動かないので、
  新しいセルが開くたびに同じ選び方をしていたためです。いまは、その契約の上でもう動いているセッションの数を見ます。
  余裕を「1 ＋ 動いている数」で割って並べるので、次のセルは空いている契約へ行きます。期限が近い契約は、
  引き続き最初のセルを受け持ちます（[#2927](https://github.com/receptron/mulmoterminal/pull/2927)）。

  確かめ方: セルを 3 つ続けて開いて、それぞれのヘッダーを見てください。以前は 1 つの契約の名前が並んでいたのが、
  別々の契約の名前になっています。並べ方の詳細は[トークンローテーション](token-rotation.html)にあります。

## 見えない変化

- `tokenRotation` を設定していなければ何も変わらず、することもありません。
- セッションは、このサーバーが Claude のプロセスを持っている間だけ「動いている」と数えます。切り離されて長く放置され、
  片付けられたものは、もう契約の重みになりません（[#2927](https://github.com/receptron/mulmoterminal/pull/2927)）。
- 依存パッケージを更新しました。MulmoCast とその型、共有の MulmoClaude パッケージ、ルーター、ビルドツールです
  （[#2930](https://github.com/receptron/mulmoterminal/pull/2930)）。

**反映されているかの確かめ方:** `tokenRotation` を設定した状態で、新しい Claude のセルを 3 つ続けて開くと、
ヘッダーが別々の契約の名前になっています。
