# 6.7.0 — 道具メニューから話す、キーボードでターミナルを動かす

**6.7.0（2026-09-29 公開）時点のスナップショットです。** アプリが変わるにつれて古くなりますが、
それは想定どおりです。最新の説明は、各節から張ったガイドを見てください。

6.6.0 で始めたセルの見出しの整理を、このリリースで終えました。下のキー割り当て（任意）のほかに、
設定は要りません。

## ほかのターミナルと話す入口は、道具メニューへ

セルの2段目にあった `forum` ボタンはなくなりました。1段目の**道具**メニュー（スパナ）を開き、
*エージェントを再起動* のすぐ上にある **ほかのターミナルと話す…** を選びます。

- この行は、**ほかのターミナルが開いているときだけ**出ます。セルが1つだけのときに無いのは不具合ではありません。
- 拡大していない並べた状態のセルからも使えます。
- 開く画面は今までと同じです（最後のやり取りを取り込む、1往復やり取りする、円卓を始める）。
  1段目の右端の下に開き、「exchanging — stop」もそこに出ます。

最新の説明: [セル同士を会話させる](conversation.html#start)

## キーボードやコマンドパレットで、ターミナルを動かす

今のターミナルを1つ動かす操作が2つ増えました。グリッドとサムネイル列では左右、一覧では上下に動きます。

- `terminal-move-prev`
- `terminal-move-next`

「今のターミナル」は拡大中のターミナル、何も拡大していなければカーソルのあるセルです。
**手動の並び順のときだけ**動きます。自動・優先度の並び順では位置をグリッドが決めるので、キーは何もしません
（1キーの割り当てはそのままターミナルに届きます）。パレットの行にも理由が出ます。

コマンドパレットにはすでに並んでいます。キーを割り当てるには、`~/.mulmoterminal/config.json` の
`keymap` に書き、サーバを再起動します。

```json
{
  "keymap": {
    "terminal-move-prev": "Alt+Shift+ArrowLeft",
    "terminal-move-next": "Alt+Shift+ArrowRight"
  }
}
```

確かめ方: ツールバーの並び順のメニューで**手動**にし、セルにカーソルを置いてキーを押すと、隣のセルと入れ替わります。

最新の説明: [キーボードショートカット](config.html#keymap)

## 休ませるのアイコンが変わりました

休ませるボタンは、**ベッドで人が寝ている形**になりました。セルの見出しと、一覧・サムネイルの ⋮ メニューの両方です。
前の三日月はダークモードの切り替えに見えていました。動きは変わりません。

最新の説明: [機能](features.html)

## 説明の吹き出しが表示の言語に

セルの説明の吹き出しと読み上げ用の名前、起動フォーム（ディレクトリのチップ、エージェントの選択、worktree の行、
再開できるセッション）のものが、5つの言語すべてで表示の言語に従うようになりました。ほかの部分は、この先のリリースで続きます。

## 設計図: 文書を段階的に

- 文書の作業が終わると、**次にできること** に同じフォルダでの次の段階が出ます
  （規約をつくったあとは「書く」「整える」、書いたあとは「整える」）。選ぶと、入力済みのフォームが開きます。
- **例から始める** の例が、土台ごと（文書のフォルダ、Firebase、ローカル）にまとまりました。
- 「1行に1つ」答える質問は複数行の欄になり、編集しても改行が消えません。
- フォルダの中のファイルを答える質問には **フォルダから選ぶ** が付き、パスを打たずに一覧から押して足し引きできます。
- プロジェクトのフォルダに `~/…` と書けます。

## 修正: セルを閉じるとプログラムも終わる

tmux の無い環境（と Run command のセル）では、切断の合図を無視するプログラムが、セルを閉じたあとも動き続けることがありました。
今は少し待ってから強制終了します。設定は要りません。確かめるには、セルを閉じて `ps` にそのプログラムが残っていないことを見ます。

最新の説明: [設計図 — 文書を扱う](blueprints.html#documents)
