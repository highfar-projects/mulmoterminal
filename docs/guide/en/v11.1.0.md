# 11.1.0 — Folders at a glance, more charts, and a quieter usage gauge

**A snapshot as of 11.1.0 (released 2026-10-21).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### See a folder in the Files pane

Open the Files pane beside an enlarged terminal and, before you open a file, the right side now shows
a folder instead of "Select a file"
([#3131](https://github.com/receptron/mulmoterminal/pull/3131)). Click a folder in the tree and it
shows that one.

- **List** shows folders first, with file sizes. Click a folder row to go into it, or a file row to
  open it (**Cmd**/**Ctrl**+click opens it in a tab of its own).
- **Gallery** shows the pictures, videos, sounds and PDFs as tiles.
- **Include subfolders** also shows what is a few levels down, each folder under its own heading.
- **Up one folder** goes to the folder above.

As you move, the tree on the left opens down to the folder and highlights it
([#3135](https://github.com/receptron/mulmoterminal/pull/3135),
[#3139](https://github.com/receptron/mulmoterminal/pull/3139)). Your choice of list or gallery is
remembered in this browser.

More: [Editing files beside a terminal](features.html#editing-files-beside-a-terminal).

### More kinds of chart

Ask for a chart and the agent can now draw more of them
([#3128](https://github.com/receptron/mulmoterminal/pull/3128),
[#3140](https://github.com/receptron/mulmoterminal/pull/3140),
[#3145](https://github.com/receptron/mulmoterminal/pull/3145),
[#3154](https://github.com/receptron/mulmoterminal/pull/3154)):

- a map of Japan or the world coloured by value (prefecture and country names in Japanese work too);
- points grouped into clusters, and a box plot for each column;
- a fitted curve over a scatter, and a histogram, both drawn from the sheet so they follow your edits;
- a word cloud, each word sized by its value;
- Pareto charts, waterfalls, two value axes, correlation matrices, calendar heatmaps, 3D.

Each chart card also saves as **SVG** and **CSV**, follows the dark theme, and several sit side by side
when there is room (one per row in a narrow Canvas,
[#3151](https://github.com/receptron/mulmoterminal/pull/3151)). If a chart cannot be drawn, the agent
is told why and fixes it before you see it.

The data-analysis skill uses all of this
([#3129](https://github.com/receptron/mulmoterminal/pull/3129),
[#3143](https://github.com/receptron/mulmoterminal/pull/3143),
[#3147](https://github.com/receptron/mulmoterminal/pull/3147),
[#3150](https://github.com/receptron/mulmoterminal/pull/3150)). Try:

> Analyse data/stores.csv. Group the stores that are alike, and show sales by prefecture on a map.

More: [Spreadsheets, charts and data analysis](spreadsheet.html#analysing-data-from-start-to-finish).

### Switch the usage gauge off, or measure less often

The Claude and Codex usage windows at the top of the grid are measured by starting a hidden `claude`
that makes one small request, about every ten minutes — and that request counts against the very
windows it measures. You can now turn it down
([#3155](https://github.com/receptron/mulmoterminal/pull/3155)):

1. Open **Settings** → **Grid header read-outs**.
2. Untick **Usage gauge** to hide it and stop measuring altogether, or
3. use **−** / **+** to measure Claude every 2 to 60 minutes (10 is the default).

It takes effect straight away. In `~/.mulmoterminal/config.json` the two settings are `usageGauge` and
`usageProbeIntervalMinutes`.

More: [Settings](config.html#settings-modal).

### Windows: cells that survive a restart, with psmux

On Windows, install [psmux](https://github.com/psmux/psmux) and MulmoTerminal uses it the way it uses
tmux elsewhere: your cells keep running when the server restarts
([#3133](https://github.com/receptron/mulmoterminal/pull/3133)).

```
winget install -e --id marlocarlo.psmux
```

Use psmux 3.4.0 or later; with an older one, Enter after a paste and a double Esc do not work, and the
server log says so. Without psmux everything still works, as before; cells just do not survive a
restart.

More: [Getting started, step 3](getting-started.html#step3).

## What looks different

### JSON files in the Files pane

A `.json` file opens as indented, coloured JSON in Preview. The Canvas view is offered only for a
MulmoScript (a file whose top level has `$mulmocast`), so an ordinary JSON file no longer shows "not a
valid MulmoScript" there ([#3141](https://github.com/receptron/mulmoterminal/pull/3141)).

### The side-by-side view stays on

If you switched the Files pane to editor and preview side by side, it is still on when you come back
from another cell ([#3132](https://github.com/receptron/mulmoterminal/pull/3132)).

### Chart cards in a narrow Canvas

Cards that were squeezed two to a row in a narrow Canvas now sit one per row, with their full titles
([#3151](https://github.com/receptron/mulmoterminal/pull/3151)).

## Under the hood

### No more "." conversations from a symlinked folder

If your workspace folder is a symbolic link (on Windows, often a link to a network share), each usage
measurement left behind a conversation that only said "." — they piled up in `claude --resume`
([#3156](https://github.com/receptron/mulmoterminal/pull/3156)). Nothing to do: they are no longer
left behind, and the ones already there are removed when MulmoTerminal starts.

**How to tell you have the fix:** start MulmoTerminal, then run `claude --resume` in your workspace.
The "reply with the single character: ." conversations older than ten minutes are gone.

### Dates in spreadsheets

Date functions such as `YEAR` and `DATEDIF` now read text like `2025-01-15`, `2025-01` or `2025年1月`
as a date, and `TEXT(A2,"yyyy-mm")` formats a date as `2025-01`. Date formats written in lower case or
in Japanese display correctly ([#3118](https://github.com/receptron/mulmoterminal/pull/3118),
[#3119](https://github.com/receptron/mulmoterminal/pull/3119)). Nothing to do.

### When a GitLab host or a repo list change applies

Adding a self-hosted GitLab or a repository in Settings applies at once; after editing
`config.json` by hand, press **Reload config file** in Settings — no restart needed. The guides and the
message for an unknown host now say so
([#3126](https://github.com/receptron/mulmoterminal/pull/3126),
[#3127](https://github.com/receptron/mulmoterminal/pull/3127),
[#3130](https://github.com/receptron/mulmoterminal/pull/3130)).
