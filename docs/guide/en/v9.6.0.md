# 9.6.0 — Move a session to another subscription from its header, and JingleScript

**A snapshot as of 9.6.0 (released 2026-10-09).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### Move a session to another subscription from its header

This applies only if you use [token rotation](token-rotation.html). A cell's header already names the subscription
it runs on. That name is now a button
([#2951](https://github.com/receptron/mulmoterminal/pull/2951)).

1. **Click the name** in the cell's header. A list opens with your subscriptions: the ones in `tokenRotation`, and
   the `/login` account when `includeDefaultLogin` is on. The one this cell runs on has a tick.
2. **Beside each subscription** you see how much of its weekly allowance is left, and below that how long until the
   week resets, for example `40% left this week` and `resets in 2d 4h 10m`
   ([#2955](https://github.com/receptron/mulmoterminal/pull/2955), [#2960](https://github.com/receptron/mulmoterminal/pull/2960)). A subscription that is out says **At its limit**. One that has not been
   measured yet shows nothing rather than a zero. The figures are the same ones the toolbar's usage gauge reads, so
   they appear once that gauge has measured.
3. **Pick one.** The session restarts on it and carries on with the same conversation. A turn that was in progress
   is stopped, as with **Restart the agent**.

![The list opened from a cell's subscription name: each subscription with its weekly room and the time until it resets, a tick on the one in use, and the one nearly out shown in amber (shown with the Japanese interface)](../images/v9.6.0-account-switch.png)

Only cells that token rotation placed offer the list. A cell on an account, a provider or a custom agent keeps the
plain label.

### JingleScript: agents can write jingles

An agent can now compose a short jingle or sound effect as a JingleScript score and play it back
([#2957](https://github.com/receptron/mulmoterminal/pull/2957)). Ask an agent in a cell for a jingle ("a short rising chime for a task finishing"). When it
renders one, the **Canvas** opens a player with the waveform, a beat grid, labelled cues you can click to jump to, a
lane of notes for each track, and a download link. The tool behind it is `manageJingleScript`; its other actions
(guide, schema, instruments, check) answer in text and show no player. Nothing to configure.

## What looks different

- **The subscription name in a cell's header is now clickable**, with the list described above.
- **The name no longer disappears after you reload the page.** Reloading, or any reconnect to a session that was
  still running, used to leave the name blank until that session was started again
  ([#2949](https://github.com/receptron/mulmoterminal/pull/2949)). It now comes back at once.
- **The reset countdown reads days, hours and minutes.** A week's reset used to say `resets in 52h 10m`; it now says
  `resets in 2d 4h 10m`, in the toolbar gauge's hover, the Token usage screen and the new list
  ([#2964](https://github.com/receptron/mulmoterminal/pull/2964)). Under a day it is unchanged.

## Under the hood

- **Server folders are grouped.** `server/agents`, `server/config`, `server/backends`, `server/session` and
  `server/infra` were each one long flat folder; they are now sorted into folders by agent or by concern
  ([#2945](https://github.com/receptron/mulmoterminal/pull/2945), [#2947](https://github.com/receptron/mulmoterminal/pull/2947), [#2953](https://github.com/receptron/mulmoterminal/pull/2953), [#2958](https://github.com/receptron/mulmoterminal/pull/2958), [#2962](https://github.com/receptron/mulmoterminal/pull/2962)). Files were moved,
  not rewritten. Nothing changes for you; it only matters if you read the source or have notes that point at an
  old path.

More: [Token rotation](token-rotation.html), [Feature list](feature-list.html).

**How to tell you have it:** with token rotation on, the subscription name in a cell's header opens a list when
clicked, and it is still there after you reload the page.
