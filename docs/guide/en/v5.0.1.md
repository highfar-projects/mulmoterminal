# 5.0.1 — An ended session says which agent it was

**A snapshot as of 5.0.1 (released 2026-09-18).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

**Nothing to configure.** Upgrade and the behaviour is there:

```bash
npx mulmoterminal@latest
```

---

## What was wrong {#what-was-wrong}

The [Conversation pane](v5.0.0.html) reads four agents today — Claude, Codex, Cursor and Copilot.
For the other three it says so plainly, which is the useful answer:

> This agent keeps its conversation somewhere this pane can't read yet.

It said that by asking what the cell was **running**: the live process, or what tmux reported the
pane's command to be. Both are gone once a session has ended — so from that moment a **grok**,
**muse** or **Antigravity** session was told something else:

> Nothing written to this session's transcript yet.

Which is a different sentence, and a false one. Its conversation existed; this host could not read
it. The same answer reached the phone's conversation view, through the same resolver.

## What changed {#what-changed}

The pane now asks the **agents' own records** rather than the process, and only when no reader
found a transcript and the process could not say. Antigravity and muse are answered from the log
MulmoTerminal already keeps of which conversation each session runs; grok is answered by looking
for the session's own directory, because a grok conversation is filed under the id the session
already has.

A live cell is unaffected: it answers from its own process, exactly as before, and none of these
lookups run for it.

## How to tell you have the fix {#how-to-tell}

You need a **grok**, **muse** or **Antigravity** session that has finished — the cell is still in
the grid, the agent is no longer running.

1. Enlarge that cell and open the **Conversation** pane.
2. Before 5.0.1 it read *"Nothing written to this session's transcript yet."*
3. From 5.0.1 it reads *"This agent keeps its conversation somewhere this pane can't read yet."*

If you only run Claude, Codex, Cursor or Copilot, there is nothing here you can see — those four
are read from their transcripts and were never affected.

Reading those three agents' conversations for real is a separate piece of work, tracked in
[#1822](https://github.com/receptron/mulmoterminal/issues/1822). This release is about which
sentence you get until then.
