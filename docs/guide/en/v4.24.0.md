# 4.24.0 — One tool for the gallery, and two more ways out of a ShapeScript result

**A snapshot as of 4.24.0 (released 2026-09-15).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

A ShapeScript release, and the only one of the two changes that can need your hands is the first.

---

## `publishShapeScript` is gone — the tool is `manageShapeScript` now {#manage}

**What breaks.** Nothing you *configure* names the old tool, so there is no setting to edit. What
can name it is text you wrote: a saved prompt, a note in a `CLAUDE.md`, a skill of your own, a
launcher chip's seed — anything that tells an agent to *"call `publishShapeScript`"*. An agent
following that today looks for a tool that no longer exists, says so, and stops.

**What to write instead.** The gallery is one tool with an `action`, the shape `manageCollection`
already had:

| You used to want | Now |
|---|---|
| publish a model | `manageShapeScript` with `action: "publish"` |
| update a post you made | `action: "update"` (it took an `id` before, and still does) |
| — | `action: "delete"` — removes your own post and every object under it |
| — | `action: "get"` — a post's readable fields **and its ShapeScript source**, yours or anyone's published one. With `save: true` it lands under `artifacts/shapes/`, where `presentShapeScript` opens it |
| — | `action: "getList"` — your own models, drafts included, newest first |

**How to tell you have it.** Ask a cell with the ShapeScript tools: *"list your tools"*. You should
see `manageShapeScript` and no `publishShapeScript`.

**The approval posture has not changed.** It stays in the **External accounts** group and is never
auto-approved: it publishes and deletes under your own Google account, and a tool is grouped as a
whole. If your cell has the gallery at all, it has `delete` too — which is the reason the prompt
still appears.

## Download GLB and STL from a ShapeScript result {#downloads}

Nothing to switch on. The `presentShapeScript` view now offers **Download GLB** and **Download STL**
beside Download USDZ:

- **GLB** — binary glTF, for the web and game engines. Vertex colours survive as `COLOR_0`.
- **STL** — binary, geometry only, every vertex baked into world space. This is the one a slicer
  wants.

Both are built in the browser from the **applied** script, so both are disabled while the editor is
holding edits you have not applied — the file you save is the model you are looking at, never a
half-typed one.

**The Copy button moved.** It is at the right end of the *Edit ShapeScript Source* bar now, next to
the text it copies, rather than up in the header.

---

## Nothing else changed

No config keys, no keymap, no agent behaviour. If you do not use the ShapeScript tools, this release
changes nothing you can see.
