# 8.7.0 — Surveys that show their results, printable STL, and a set-aside cell that stays put

**A snapshot as of 8.7.0 (released 2026-10-03).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### A survey that shows respondents the results

Ask the agent for a survey and say that people who answer should see the results — for example
"make a survey for my talk, and show everyone the totals after they answer"
([#2884](https://github.com/receptron/mulmoterminal/pull/2884)). It builds it from the new **survey-results**
template:

- After answering, a respondent sees each multiple-choice question with how many chose each option and the share.
  Before answering they see only the questions, so the results do not steer the answer.
- Their address, name and comments are seen by you alone, on the app's member page (`/m/{slug}`), which also lists
  each person with their answers.
- Only the options you declared are counted. Anything else someone manages to send is not counted and never shown on
  the public page.

A survey that keeps its results to yourself is still the default — ask for nothing and you get that. See
[Shared apps](shared-apps.html).

### Export a ShapeScript model for a 3D printer

Ask the agent to export a model as STL for printing
([#2876](https://github.com/receptron/mulmoterminal/pull/2876)). It writes one watertight solid in millimetres, Z up,
resting on the bed, and tells you where the file is and whether it is printable: its size, how many separate bodies
it has, and warnings for parts that only touch or float loose. Nothing to set up.

## What looks different

- **Blueprint interviews give you room to answer**
  ([#2883](https://github.com/receptron/mulmoterminal/pull/2883)). Free-text questions are a multi-line box you can
  resize instead of a one-line field, the text is larger, and every question shows an example answer in grey. Questions
  whose answer is a single value, like an app name, stay one line. See [Blueprints](blueprints.html).
- **ShapeScript models built with `union`, `difference` or `intersection` look a little different**
  ([#2876](https://github.com/receptron/mulmoterminal/pull/2876)). They are now built by the same engine everywhere, so
  their surfaces are closed and keep each part's colour. Most models differ by a fraction of a percent of pixels. A
  lattice inside a `union`, which used to time out, now previews.

## Under the hood

- **A set-aside cell no longer wakes up by itself**
  ([#2886](https://github.com/receptron/mulmoterminal/pull/2886)). If a cell's connection was down for more than 30
  seconds — the tab closed, the laptop asleep, the server restarted — the cell came back to full strength as soon as it
  reconnected, with nobody typing. The terminal's automatic answers to tmux's questions were being counted as typing.
  Now only what you type wakes it. How to tell you have the fix: set a cell aside, close the tab, wait a minute, open
  MulmoTerminal again — the cell is still faded. One key, Shift+F3, looks exactly like one of those answers and no
  longer wakes a set-aside cell. See [Features](features.html).
- **Faster and sturdier ShapeScript** ([#2876](https://github.com/receptron/mulmoterminal/pull/2876)). Combining shapes
  is 2-3 times faster, and rendering a very large model to a picture no longer fails.
- **Shared apps no longer publish an account id in their public rows**
  ([#2879](https://github.com/receptron/mulmoterminal/pull/2879),
  [#2880](https://github.com/receptron/mulmoterminal/pull/2880)). The `project-board` and `magazine` templates now
  use a per-app pseudonym where they used the account's id, so a row cannot be linked to the same person in another
  app. Apps you already published from them keep working as they are; rebuild one to get the change.
- The shared-app publisher and other libraries were updated
  ([#2877](https://github.com/receptron/mulmoterminal/pull/2877),
  [#2878](https://github.com/receptron/mulmoterminal/pull/2878),
  [#2887](https://github.com/receptron/mulmoterminal/pull/2887),
  [#2888](https://github.com/receptron/mulmoterminal/pull/2888)).

Nothing here needs doing.
