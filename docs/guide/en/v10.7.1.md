# 10.7.1 — Keep part of a subscription's week for yourself

**A snapshot as of 10.7.1 (released 2026-10-16).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

This release is for people who use **token rotation** — several Claude subscriptions that
MulmoTerminal takes turns using. If you do not use it, nothing changes for you.

## New features

### Leave part of a subscription's week unused

Token rotation spends every subscription until its weekly limit is nearly gone (98%). If one of them is
also the subscription you use outside MulmoTerminal — on your phone, in Claude.ai, on another machine —
you can now tell rotation to leave some of its week alone
([#3065](https://github.com/receptron/mulmoterminal/pull/3065),
[#3064](https://github.com/receptron/mulmoterminal/issues/3064)).

1. Open `~/.mulmoterminal/config.json`.
2. Under `tokenRotation` → `tokens`, find that subscription's entry and add `"reserveWeeklyPercent"`
   with the share to keep, in percent:

   ```json
   { "id": "personal", "label": "Personal", "email": "me@example.com", "keychain": "mulmoterminal-token-personal", "reserveWeeklyPercent": 5 }
   ```

3. Settings → **Reload config file** (no restart needed).

With `5`, that subscription counts as full once its week reaches 95%:

- no new session starts on it;
- a session already running on it moves to another subscription when it finishes its current turn,
  continuing the same conversation, with one line in the cell saying so;
- even when every other subscription is used up, rotation does not dip into the 5%.

Any value above 0 and up to 99 works. Anything else is ignored, and the entry behaves as if it had no
reserve. Entries without the field work exactly as before.

**How to tell it worked:** More features → Token usage shows each subscription's weekly room. When the
reserved one reaches its line, new cells open on the others.

More: [Token rotation → Keeping part of a week back](token-rotation.html#keep-week-back).

## What looks different

Nothing. The new setting lives only in the config file.

## Under the hood

- Nothing else changed in this release. Nothing needs doing.
