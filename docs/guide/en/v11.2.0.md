# 11.2.0 — Formulas that answer a table

**A snapshot as of 11.2.0 (released 2026-10-22).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### Formulas that fill the cells beside them

A formula in the spreadsheet on the Canvas can now give back a whole table, not just one value. The
answer fills the cells to the right and below the formula, as in Excel 365
([#3157](https://github.com/receptron/mulmoterminal/pull/3157)):

- `=SORT(UNIQUE(A2:A100))` lists each value once, in order;
- `=FILTER(A2:C100, C2:C100>1000)` keeps only the rows you want;
- `=GROUPBY(A2:A100, C2:C100, SUM)` gives one row per group with its total, and `PIVOTBY` crosses two;
- `=Data!A1:C10` on its own copies a range.

If one of those cells already holds something, the formula shows `#SPILL!` instead; clear the cells
and it fills them. Other formulas, and charts the agent draws from the sheet, read the filled cells
like any others. So you can ask, for example:

> Total sales by region on a new tab with a formula, and chart it from there.

and the table and the chart keep up when you change the data.

More: [Spreadsheets, charts and data analysis](spreadsheet.html#functions-you-can-use).

### Many more functions

Also new in the spreadsheet: `LET` and `LAMBDA` (with `MAP`, `BYROW`, `BYCOL`, `REDUCE`), `LINEST`
and `FREQUENCY`, `FORECAST.ETS`, many more tests (chi-squared, ANOVA, Mann-Whitney and others), the
`.EXC` versions of `PERCENTILE` and `QUARTILE`, and `RAND`. So more of an analysis stays a formula
that recalculates, instead of a number the agent worked out once.

More: [Functions you can use](spreadsheet.html#functions-you-can-use).

## What looks different

Nothing moved. A formula that answers a table looks like ordinary values in the cells it fills.

## Under the hood

### Random numbers that hold still

`RAND`, `RANDBETWEEN` and `RANDARRAY` give the same numbers every time the sheet is calculated,
unlike Excel, so the agent and you see the same table
([#3157](https://github.com/receptron/mulmoterminal/pull/3157)). Nothing to do.

### Updated libraries

The spreadsheet engine and several libraries were updated
([#3157](https://github.com/receptron/mulmoterminal/pull/3157),
[#3158](https://github.com/receptron/mulmoterminal/pull/3158)). Nothing to do.
