# 9.5.0 — A UFO joins the heat pictures, and two quiet fixes

**A snapshot as of 9.5.0 (released 2026-10-08).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### A UFO among the playful effects

The occasional picture that appears on a terminal has a new one: a UFO. It hovers and bobs while things are
quiet, beams down and rocks harder as the machine heats up, runs its rim lights red at the top, and shoots off
into the sky at the end
([#2939](https://github.com/receptron/mulmoterminal/pull/2939)).

- **Nothing to turn on.** The default is `"random"`, so each session picks its own picture and the UFO is now
  one of the choices. Some sessions will show a different picture than before.
- **To always get the UFO**, put it in your config and reload the tab:

  ```json
  { "playfulEffects": "ufo" }
  ```

- **To switch the pictures off**, use the on/off switch in Settings → **Theme**, or write
  `{ "playfulEffects": "off" }`.

## What looks different

- Only the new UFO picture, when a session shows it. Nothing else on screen moved.

## Under the hood

- **The usage gauge no longer switches fullscreen off.** If you set `"tui": "fullscreen"` for Claude Code and
  your cells quietly came back inline after a Claude Code update, this was the cause: the hidden session that
  reads your usage was ended seconds after it answered, and Claude Code counted that as a failed start
  ([#2940](https://github.com/receptron/mulmoterminal/pull/2940)). The hidden session now starts with the
  classic renderer, so it is no longer counted. Nothing needs doing for new cases.
  - **If it already happened to you**, Claude Code has written a `fullscreenAutoDisabled` entry into that
    login's `.claude.json`. This release does not remove it; delete that entry yourself if you want fullscreen
    back.
- **A stuck git helper can no longer hold the status of a worktree.** A tool that git started and left running
  used to keep the status read waiting, and every later read for that worktree waited behind it. The read now
  ends at its time limit and takes the leftover process with it
  ([#2942](https://github.com/receptron/mulmoterminal/pull/2942)). Nothing needs doing.
- Guide pages only: the token-rotation page explains restarting an agent that hit a usage limit and the Token
  usage screen ([#2934](https://github.com/receptron/mulmoterminal/pull/2934),
  [#2938](https://github.com/receptron/mulmoterminal/pull/2938)).

More: [Token rotation](token-rotation.html), [Settings and config](config.html).

**How to tell you have it:** with `{ "playfulEffects": "ufo" }` in your config, a session that heats up shows the
UFO; and a Claude Code update no longer leaves a new `fullscreenAutoDisabled` entry behind.
