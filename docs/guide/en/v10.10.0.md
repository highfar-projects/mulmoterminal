# 10.10.0 — Several machines on one phone, and charts that follow a spreadsheet

**A snapshot as of 10.10.0 (released 2026-10-19).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### More than one machine under one Google account

If you use MulmoTerminal on two computers — a work Mac and a home Linux box, say — both can now
connect to the phone with the same Google account
([#3106](https://github.com/receptron/mulmoterminal/pull/3106),
[#3092](https://github.com/receptron/mulmoterminal/issues/3092)). Each one appears on the phone's host
list as **MulmoTerminal — <machine name>**; tap the one you want.

- **Nothing to do with one machine.** The machine you were already using keeps its old channel, and the
  phone list looks as before.
- **A second machine**: upgrade it, sign in with the same Google account and press **Connect**. It picks
  a channel of its own and keeps it in `~/.mulmoterminal/remote-host.json`.
- **If you had already connected both machines before this release**, they were sharing one channel.
  After upgrading, the one that connects first keeps it and the other moves to its own. If one still
  shows the other's sessions, delete `~/.mulmoterminal/remote-host.json` on that machine and press
  **Connect** again.
- **A machine you no longer use** leaves the list after 30 days without connecting. To remove it
  sooner, tap the bin icon beside it on the phone (offline machines only).

The host list and the bin icon come with the MulmoServer update, which is already live.

More: [Phone — More than one machine](phone.html#several-machines).

### Charts that follow the spreadsheet

A chart the agent draws from a spreadsheet now points at the sheet's range instead of copying the
numbers ([#3099](https://github.com/receptron/mulmoterminal/pull/3099),
[#3096](https://github.com/receptron/mulmoterminal/issues/3096)). Change a number in the sheet and the
open chart redraws a few seconds later. A spreadsheet left open also reads its file again when the agent
or another program changes it ([#3105](https://github.com/receptron/mulmoterminal/pull/3105), with the
spreadsheet plugin 4.2.0).

More: [Change the data and watch](spreadsheet.html#analysis-change-and-watch).

### Open a CSV as a spreadsheet from the Files pane

In the Files pane beside a cell, right-click a `.csv` or `.tsv` file and choose **Open as a spreadsheet
(copy)** ([#3111](https://github.com/receptron/mulmoterminal/pull/3111),
[#3110](https://github.com/receptron/mulmoterminal/issues/3110)). The file appears on that cell's Canvas as
a spreadsheet, without asking an agent.

- It is a **copy**: editing the sheet never changes the CSV. Each click makes a new copy.
- Plain numbers become numbers you can use in formulas; anything else (`1,200`, dates) stays text.
- Up to 5,000 rows. A larger file is refused with the reason; ask the agent to analyse it instead.

More: [Opening a CSV as a spreadsheet](spreadsheet.html#open-csv-as-spreadsheet).

### Folder suggestions in the launch form

The **Working directory** field of the launch form now suggests folders when you pause typing for a
second, like Tab in a shell ([#3102](https://github.com/receptron/mulmoterminal/pull/3102),
[#3098](https://github.com/receptron/mulmoterminal/issues/3098)). **↑** / **↓** choose, **Tab** or a click
takes one and lists the next level, **Esc** closes. A folder that does not exist is refused in the form:
the play button is greyed out and the field says why.

More: [Which directory to launch in](basics.html#launch-dir).

### The data-analysis skill does more

`/mulmoterminal-data-analysis` (or just "analyse sales.csv") got four additions:

- **Statistics are formulas.** Correlation, slope, averages per group and so on go into the sheet as
  formulas, so they recalculate when you edit the data
  ([#3099](https://github.com/receptron/mulmoterminal/pull/3099)).
- **Functions of your own.** For a method the sheet has no function for, such as a moving average, the
  agent can add a function to the workbook itself. It is JavaScript run sealed off in the browser, with
  no access to files or the network ([#3112](https://github.com/receptron/mulmoterminal/pull/3112),
  [#3097](https://github.com/receptron/mulmoterminal/issues/3097)).
- **Large files.** Above about 5,000 rows the agent totals the file first, through a read-only
  collection, and puts the totals on the sheet
  ([#3109](https://github.com/receptron/mulmoterminal/pull/3109),
  [#3104](https://github.com/receptron/mulmoterminal/issues/3104)).
- **Keep it as your own skill.** When you like the result, the agent offers to save the analysis as a
  skill, so the next file of the same kind takes one sentence
  ([#3108](https://github.com/receptron/mulmoterminal/pull/3108),
  [#3107](https://github.com/receptron/mulmoterminal/issues/3107)).

More: [Analysing data from start to finish](spreadsheet.html#analysing-data-from-start-to-finish) and
[Functions of your own](spreadsheet.html#workbook-functions).

## What looks different

- **The launch form greys out the play button for a folder that does not exist**
  ([#3102](https://github.com/receptron/mulmoterminal/pull/3102)). Before, the cell opened and then
  reported the error.
- **The phone's host list can show several MulmoTerminal rows**, one per machine
  ([#3106](https://github.com/receptron/mulmoterminal/pull/3106)).
