# 整えるリポジトリを用意して信頼する

作業中のフォルダとは別に、整える用のコピーを用意します。途中で止まらないよう、Claude Code に一度だけ信頼させます。

1. 別の場所に clone します（例: `git clone git@github.com:{{REPO}}.git ~/blueprint-trials/{{NAME}}`）。
2. そのフォルダで `claude` を起動し、「このフォルダを信頼しますか？」に「はい」と答えて、すぐ終了します。
   clone したフォルダは git のリポジトリなので、親のフォルダを信頼していてもこの一回が要ります。
3. 設計図の「新しく作る」で、このフォルダをフルパスで指定します。

終わったら「済み」と返信してください。
