# fix: a review gate says which step the approval lets start

## 問題

文書のビルドの「承認待ち」の札は、止まっている工程の名前と説明（例: 「構成を決める — 部分ごとに…決める」）の下に「ここまでの成果を読んでから進めてください」と出る。承認は工程の**前**に立つので、読むのは要旨（`brief.md`）なのに、構成ができて承認を待っているように読める。実際に「文書を書く」を通して回して気づいた。

## 方針

- `gates.review` の文に `{step}` を入れ、「「{step}」を始める前に、ここまでの成果を読んで確かめてください。承認すると、この内容をもとに「{step}」に進みます。」とする（5 言語）。
- 実行画面は `t(gateKey(gate), { step: current.title })` で渡す。ほかの承認（費用・本番・削除・サインイン）の文は「この工程では…」で、もともと工程の前の文として読めるので変えない。
