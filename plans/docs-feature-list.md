# docs: 全機能リストをガイドに作り、リリースのたびに更新する（#2818）

## 何を作るか

`docs/guide/{ja,en}/feature-list.md` — 今ある機能をすべて、入った版を添えて一行ずつ並べた索引。

- 既存の `features.md`（機能リファレンス）は、代表的な機能の使い方を詳しく書くページ。こちらは、すべてを短く並べる。
  詳しい使い方は、各テーマの見出しから既存のガイドのページへリンクで渡す。
- テーマは 12: グリッド / エージェント / 会話 / スマホ / Files / git・PR / コマンドパレットとキー / 設定 / Canvas・コレクション /
  設計図 / コストと負荷 / 動かし方（起動・言語・リリースノート）。
- 各行に、入った版を `(vX.Y.Z)` の形で添える。spec はこの形だけを版として読む（Node の版のような、ほかの数字は読まない）。
- バグ修正・内部の変更・廃止された機能は入れない。

## どう作ったか

ChangeLog（0.6.0〜8.1.0、116 版）を 5 つの区間に分けて、利用者に見える追加をテーマ・版・PR ごとに抜き出した。
同じ機能が何度か広がったものは、最初に入った版の行にまとめた。あとの版で廃止・置き換えられたものは落とした。

## リリース手順への組み込み

CLAUDE.md の「Publishing a release」に 4 つ目として足した。リリースのたびに、その版の追加を足し、廃止されたものを消し、`as_of:` を新しい版に動かす（日英とも）。

`test/docs/feature-list.spec.ts` が止める:

- `as_of` が `package.json` の版と一致しないと赤。
- `(vX.Y.Z)` に、出そうとしている版より新しいものがあると赤。
