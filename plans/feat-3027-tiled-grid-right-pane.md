# feat(grid): 拡大していないグリッドでも右ペインを出す (#3027)

## 決めたこと

| 論点 | 決定 |
| --- | --- |
| タイル表示でペインが映すセル | メニューで開いたセルに固定。フォーカス移動では動かない |
| 全幅表示 | タイル表示では常に左右分割。全幅は拡大表示のときだけ |
| 対象ペイン | 全部。メニューの「先に拡大」を外す |

## 仕組み

ペインは今も「拡大を閉じても unmount せず隠すだけ」（#1378）。だから新しい置き場所は作らず、
`zoomRow` をタイル表示中も見せ、`.zoom-main` だけ隠したまま、ステージを横並びにして
グリッドの右へ回す（`order-last`）。拡大とタイル表示の往復で同じ要素のままなので、
Files の編集バッファも残る。

### ペインの乗るセル

- `paneUid`（今ペインが乗っているセル）はそのまま。
- 新しく **`tiledPaneUid`**: タイル表示中にペインが乗るべきセル。タイル上でメニューを押すとそこへ移る。
  再ルートの watcher が `paneUid` を動かすたびに追従させるので、拡大を閉じたときは
  直前まで乗っていたセルに残る。
- 再ルートの watcher の入力を `[zoomed, expandedUid]` から **`paneTargetUid`**
  （拡大中は `expandedUid`、タイル表示中は `tiledPaneUid`）に変える。Files の flush・snapshot・
  再ルートは一本のまま。
- ペインの中身（セッション・cwd・agent・差し込み先・質問・Canvas 可否）は
  **`paneCellUid` = `expandedUid ?? paneUid`** から読む。拡大中は今と同じ値になる。
- 自動で開く動作（描画・質問・`showInPane`）は今まで通り **拡大中のセルだけ**。タイル表示で
  昔閉じたペインのセルに勝手にペインが出るのを避けるため。

### 表示条件

タイル表示でペインを出すのは、ペインが開いていて、かつ乗っているセルが今のページにあるときだけ
（タイル表示は 1 ページ分のセルしか受け取らない）。無ければ隠す（unmount はしない）。

### メニュー

- ペイン項目は常に押せる。`enlargeFirst` の文言は消す。
- Canvas / Collections の可否はペインが乗っているセルの分しか分からない。そのセル以外のタイルでは
  Canvas は押せる（開いて使えなければペインが理由を言う）、Collections は今まで通り出さない。
- ヘッダの操作は `pressPane` を通す。ペインが乗っているセルなら開閉、別のセルならそのセルへ移して開く
  （タイル表示では拡大しない）。

### 全幅

`paneFull` に `zoomed` を条件として足す。

### その他

- パスメニューの「アプリでファイルを見る」も、タイル表示では拡大せずにグリッドの右へ Files ペインを出す。
  タイル上の未読 Canvas チップ（`open-canvas`）は今まで通り拡大して開く。
- ペイン幅の上限はタイル表示ではステージ幅から測る。
- ターミナル出力のパスクリック（#910）は、タイル表示でも Files ペインが見えていて cwd が合えばペインに出す。
- タイル上の未読 Canvas チップは、そのセルの Canvas がペインに見えている間は数えない（`paneShown`）。

## 範囲外

- Files ペインのキー操作をタイル表示でも効かせること（`runCellShortcut` は拡大中のセルを要求する）
- タイル表示で描画が来たときに GridView がそのセルを拡大する動作は変えない
