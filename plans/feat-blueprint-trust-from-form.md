# feat: an untrusted folder can be trusted from the form, and the form keeps its answers (#2463)

## 問題

自分の文書のフォルダで始めると「信頼していません」で断られ、どこで何をすればよいか分からない。確かめに行くと設計図の画面を離れ、入れた答えが消える。

## 方針

- 断り `untrusted` に `trustIn` を足す。Claude Code を開いて信頼の確認に答える場所で、フォルダがあればそのフォルダ、これから作るならその親（`trustPlace`、`server/blueprint/newFolder.ts`）。
  - 実行の途中で断る場合（executor）は、フォルダが必ずあるのでフォルダそのもの。
- フォームは断りが `untrusted` のとき「ここで Claude Code を開く」を出す。押すと次のことをする。
  - いまの入力（土台・種類・答え・フォルダ・選んだ例）を `keepFormFill` で覚える。
  - `openTerminalAt(trustIn, null, "claude")` で新しいセルを開く。
  - 信頼の確認には本人が答える。こちらは答えない。
- 次の段落の二つの仕組みを、一つの `FormFill` にまとめた。
  - 「次にできること」の引き継ぎ（`after` あり）。
  - 離れる前の入力（`preset` あり）。
  - 戻ったフォームは同じ仕組みで答えを埋め、例も戻すので、見本の文書もそのまま置かれる。「入れていた内容を戻しました」と出す。
- フォルダを打ち直したら、ボタンは消す（別のフォルダの話になるため）。
- 断りの文（5 言語と英語）は `{trustIn}` を名指しする。

## 範囲外

- 工程の途中で出る「信頼していません」の通知（実行画面）からのボタン。
- ページを読み込み直すと、覚えた入力は消える（メモリの中だけ）。
