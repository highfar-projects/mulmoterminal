# ファイルのペインで CSV / TSV を表計算で開く（#3110）

## 決めたこと

- 入口はファイルの行の右クリック **表計算で開く（コピー）**。セルの横のペインだけ（`canvas` がある行）。
- ペインのタブごとの Canvas 表示にはしなかった。あの表示はタブを切り替えるたびにカードを作り直すので、CSV ではそのたびに新しいコピーができ、編集が消える。代わりに、一度だけコピーを作り、セルの Canvas の流れに置く（エージェントのカードと同じ。再読み込みでも戻る）。
- 読むのは、ペインが使っている `/api/files/browse/text`（セルのディレクトリの中に限る）。保存は `presentSpreadsheet` の成果物の置き場。新しく読める範囲は増えない。
- 変換は純粋な関数（`src/composables/csvSpreadsheet.ts`）。ただの数は数に、それ以外は文字のまま。`=` で始まる値は `'` を付けた文字にする（表のプラグインに文字の印が無いので、Excel の慣習に合わせた）。
- 5,000 行まで。分析スキルが集計に切り替える目安と同じ。
- CSV を読む関数（`parseDelimited`）は `common/delimited.ts` に移し、サーバーの表のプレビューと共有する。

## ついでに直したもの

- `TerminalGrid.openCanvasFor`：ファイルのペインがすでに横にあるタイルを拡大すると、ペインのセルが変わらないので、`canvasHasCard` を取り直す watch が走らず、置いたばかりのカードがあっても「Canvas が有効でない」と出た。拡大したあとも取り直す。

## 確かめたこと

- 隔離したサーバーで、ワークスペースのシェルのセルからファイルのペインを開き、`data/stores.csv` を右クリック → 表計算で開く。セルの Canvas に `stores.csv` の表が出た（`1,090` は文字のまま、数は数）。コンソールの誤りは無し。上の直しの前は「Canvas が有効でない」と出た。
- `yarn format` / `lint` / `typecheck` / `build` / `test` が通る。
