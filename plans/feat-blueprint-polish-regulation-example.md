# A polish example for a regulation (#2754)

#2747 gave polish the kind 「規程・社内規則」 (legal/statute) and four viewpoints for it. This adds an example beside
the manual one (#2753), on a subject no other example uses: a company-car regulation.

- `presets/shayo/kitei.md` — self-written. Under legal/statute chaff reports one thing: an empty intensifier
  (「非常に重要」) in a sentence that already says why, so it can be fixed without adding a fact. The viewpoints each
  have one gap: no statement of whom it applies to, a report duty with no deadline, nothing on what follows a breach,
  and a disaster exception in 第6条 that 第3条 does not point to.
- legal/statute allows sentences up to 300 characters and keeps register mixing experimental, and polish runs no
  experimental rule, so neither is used as the chaff finding.
- Answers: 「規程・社内規則」, chaff's own style, one file. The guide's list of examples names it in both languages.

A real build from the example finished: 「非常に」 was removed and nothing else changed, and all four viewpoints came
back as questions for the writer.
