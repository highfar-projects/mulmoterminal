# A compare example for a regulation revision (#2756)

A comparison table (新旧対照表) is written most often for a revised internal regulation, and compare's only example
was a contract. This adds a self-written travel-expense regulation in two versions.

Between `kyu.txt` and `shin.txt`: a proviso is added to 第2条, the daily allowance (第4条) and the hotel cap (第5条)
rise, 第6条 (coupons) is removed, 第7条 (settlement) moves up to 第6条 with a shorter deadline, and a new 第7条 sets
the date it takes effect. The settlement article's reference 「第3条から第5条まで」 keeps pointing at the same articles.

A real build from the example finished with every article paired as above. The guide's list of examples names it in
both languages.
